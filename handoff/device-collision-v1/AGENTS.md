# Role and boundary

This is a reviewed local release. Only this immutable package, neutral
project governance, approved public sources and independent implementation
materials may enter a fresh implementation workspace.

Read README.md, spec.md and cases.json. Preserve published releases; corrections
require a new revision. Do not retrieve analyst directories, original executables,
recovered code, source-derived synthesis models or task transcripts. A role label
is not access isolation. Shared storage containing analyst sources does not
establish clean implementation conditions. Return questions through the
implementation question register for an analyst and reviewer to resolve.

The comparison code only measures output; its result cannot establish behavior
outside the listed vectors, events, windows, rates and metrics. Missing evidence
is unknown. Reference self-comparison is not a candidate compatibility test.

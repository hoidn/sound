# Released package role and access instructions

This is a reviewed local release for its explicit partial scope. Application
implementation requires a fresh, restricted implementation workspace containing
only permitted materials. Publication of this package does not provision one.
Do not begin clean implementation in the analyst checkout.

In an approved implementation workspace, permitted inputs are the pinned release,
neutral governance, approved public sources, and independently authored candidate
code, designs and tests. Raw binaries, analysis, decompilation, source traces,
research drafts, verification internals and analyst conversations are forbidden.
A role prompt does not restrict filesystem access. Report missing isolation.

Read README.md and spec.md before cases.json. Requirements apply only to their
explicit partial scope. No source-code structure or required parser entrypoint is
specified. A candidate adapter may expose assignment meaning for comparison;
this does not impose an internal architecture.

Preserve a published release unchanged. Request a reviewed revision for gaps;
do not silently extend unknown behavior. Record candidate-only tests separately
from reference comparisons, including exact package and candidate hashes.
Nothing here authorizes package installation, network publication or messages.

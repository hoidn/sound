# Package role and access instructions

This is a staged handoff candidate awaiting a separate review. It is not a
released handoff and not an implementation input. After review and
publication, application implementation requires a fresh, restricted
implementation workspace containing only permitted materials. Publication does
not provision one. Do not begin clean implementation in an analyst checkout.

In an approved implementation workspace, permitted inputs are the published
release, neutral governance, approved public sources, and independently
authored candidate code, designs and tests. Raw binaries, analysis, recovered
program code, source traces, research drafts, verification internals and
analyst conversations are forbidden. A role prompt does not restrict
filesystem access. Report missing isolation.

Read README.md and spec.md before cases.json. Requirements apply only to their
explicit partial clauses. No source-code structure, parser entry point or data
structure is specified. A candidate adapter may expose the comparison labels;
this does not impose an internal architecture.

Preserve this package unchanged. Do not extend unknown or excluded behavior.
Request a reviewed revision for gaps. Record candidate-only tests separately
from reference comparisons, with exact package and candidate hashes. Nothing
here authorizes package installation, network publication or messages.

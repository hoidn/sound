# Package role and access instructions

This is an unreviewed draft, not an approved implementation target. A fresh restricted
implementation workspace is required before application implementation.
A prompt or role label does not restrict filesystem access.
Do not begin clean implementation in an analyst checkout.

After an approved release, a restricted implementer may use only the released
package, neutral governance, approved public sources and independently authored
candidate code, design and tests. Original binaries, analysis, decompilation,
research drafts and analyst conversations remain forbidden.

Read README.md and spec.md before cases.json. The measurement code computes
only audio-comparison metrics; it is not device synthesis code and specifies no
candidate structure. The comparison representation is a project convention.
Parameter names identify controls, not original class names or memory fields.

Do not extend excluded inputs, infer file-to-device mappings or grade omitted
modal estimates. Do not claim application or arm64 execution. Report the exact
package hash, candidate hash, numerical environment and measured scope. After
publication preserve every byte; corrections require a reviewed revision.
Nothing here authorizes tooling installation, publication or messages.

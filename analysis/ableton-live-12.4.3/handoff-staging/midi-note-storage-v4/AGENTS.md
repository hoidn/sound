# Package role and access instructions

This is an unreviewed staging candidate. Do not use it as an implementation
input. Independent content review, an external exact-tree seal and coordinator
local publication are required first. A published release may be used only in
a fresh restricted implementation workspace containing permitted materials;
publication does not provision one. Do not begin implementation in an analyst
checkout. No role prompt restricts filesystem access.

In an approved implementation workspace, permitted inputs are the published
release, neutral governance, approved public sources and independently authored
candidate code, designs and tests. Raw binaries, analysis, decompilation,
source traces, research drafts, verification internals and analyst conversations
are forbidden. Report missing isolation.

Read README.md and spec.md before cases.json. Eight validate-notes cases judge
bounded comparison projections. Six retain the group rules; two add only the
specified local reader refusals over decoded Notes input. No public validation
API, native call, reader entry point, internal data structure or implementation
pipeline is required. An implementation may validate at any suitable point.
Two input_projection records reuse the supplied authored base fixture and state
exact domain edits; they do not add a public open or saved-state expectation.

Preserve the package unchanged. Do not extend excluded inputs or behavior without
an expectation. Request a reviewed revision for gaps. Record candidate-only tests
separately from reference comparisons, with package and candidate identities.
Do not obtain or embed Sets, clips or other content shipped with the target.
Nothing here authorizes installation, network publication or messages.

# Package role and access instructions

This is a reviewed local release for its explicit partial scope. Application
implementation requires a fresh, restricted implementation workspace that
contains only permitted materials. Publication of this package does not
provision one. Do not begin clean implementation in an analyst checkout.

In an approved implementation workspace, the permitted inputs are the published
release, neutral governance, approved public sources, and independently
authored candidate code, designs and tests. Raw binaries, analysis,
decompilation, source traces, research drafts, verification internals and
analyst conversations are forbidden. A role prompt does not restrict
filesystem access. Report missing isolation.

Read README.md and spec.md before cases.json. Requirements apply only to their
explicit partial clauses. No source-code structure, processing graph, data
structure or audio interface is specified. A candidate adapter may evaluate
the computation cases and supply the test signals of the render cases; this
does not impose an internal architecture. The WAV fixtures are generated test
signals, not recordings.

Preserve this package unchanged. Do not extend excluded behavior or inputs
without an expectation. Request a reviewed revision for gaps. Record
candidate-only tests with exact package and candidate hashes. Render results
show conformance to this contract, not compatibility with the original
application. Nothing here authorizes package installation, network
publication or messages.

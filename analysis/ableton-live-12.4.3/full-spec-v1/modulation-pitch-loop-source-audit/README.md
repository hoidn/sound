# Modulation, Pitch and Loop retained-source audit

This is a partial source-only audit of the ten exact current canonical Audio
Effects h2 families: Auto Pan-Tremolo, Auto Shift, Beat Repeat, Chorus-Ensemble,
Looper, Phaser-Flanger, Shifter, Spectral Resonator, Spectral Time and Vocoder.
It does not audit the whole Audio Effects chapter or the separate Legacy devices.
The current owner and all historical files remain unchanged. Independent review
is pending as of author freeze. No requirement or case is adopted here.

`audit.json` retains all 332 exact raw-spanned text contexts: 231 paragraphs,
60 list items and 41 headings (10 h2, 25 h3, six h4), with no tables/cells in these
sections. Each has a quoted, hashed whole-context assessment and exact source
pointer, plus catalog-qualified requirement/case/action pointers. These manual
judgments are not atomic assertion counts or semantic closure. Catalog citations
identify compared subsets: each assessment distinguishes actual selected actions,
control inspection, documentary roles, missing actions/context and research only.
The 22 proposal groups and eight questions are bounded audit proposals; every new
documentary/actual expected/comparison is null/U/unexecuted, with zero normative
IDs, cases, adoption, coverage credit or complete topics.

All primary texts, all 106 current catalog contracts, all 186 full case records
and the full common/per-device stimulus recipe were read. These include 96 D12
and ten U clauses; 46 control, nine state and 41 signal proposals plus 90 U
lifecycle records. The 96 D12 contract bodies match the immutable canonical
snapshot exactly; the ten U catalog bodies expand the canonical U headings and
shared lifecycle matrix. The audit preserves these existing forms literally,
without claiming every lifecycle setup is adequate or complete. The original
owner review, focused R2 heading correction and reviewed spectral association
correction/reconciliation were read; unrelated packets in the combined editorial
review are not inherited semantic approvals. One initial case dump truncated;
its missing 25–35 range was explicitly reread before judgments.

The full 1137-context source parse is used only for literal h2 filtering. There
are 105 literal resources in the selected families: 44 image start tags, 43
captions and 18 links. Their URL/empty-alt/caption/link roles were read; image
pixels, repeated responsive image variants and linked destination contents were
not inspected. Two chapter-introduction navigation links in the initial 107-row
projection are explicitly excluded and retained as excluded provenance in
`inputs.json`. The checker uses each heading's own source position to select
resources, avoiding ancestor-h1 overwrite. No external companion chapter's
semantics are claimed.

The source remains the exact 588328-byte retained HTML SHA-256
`9cb15cb3d80bda4771e5add2c2b74f5c57d73ee8850e198acf7cf8a51dfd1299`.
Its capture is date-only 2026-10-19, UTC null, current Version 12; publication and
exact target 12.4.3 applicability remain unknown. Original spectral source IDs
remain historical: the reviewed association maps Resonator to Transmute/8118
and Time to Spectral/7423. The carried folder ledger retains eight and six real
presets and fourteen excluded dot-underscore sidecars; it is not a new decode,
constructor/default, algorithm or runtime observation. All retained schema,
preset/history and correction files are inert byte pins only.

True existing subsets remain, including Blend endpoints, Duty Cycle's explicit
deterministic positive, Auto Shift correction-inactive processing, Resonator's
Chorus Rate-zero amplitude exception, both Looper currently-playing halves,
latest-overdub Undo/Redo, and both Insert-Looper taps. Inspection is not promoted
to a gesture: for example Chorus Rate still needs actual dial/display dragging,
Phaser's other display controls need edits, and Vocoder band attenuation needs an
actual click. Shifter's raw Hertz Delay wording and Spectral Time's mixed X-Fade
ms/percentage wording remain unresolved. Frz>Dly and Dly>Frz stay distinct; no
unconditional freezer-feeds-delay, latency calibration, FFT/window/filter kernel,
RNG/distribution/finite-traversal, pitch/tuning codec, clock, mix/gain or file law
is inferred. Generic routing, MIDI/MPE, conversion, mapping, tuning, media and
transport protocols stay with existing owners; those other chapters were not
fully audited here.

Future signal probes require actual recognized NONEMPTY input, active wet and
output route, and productive effect-control response first. Both independent
channels, sources, notes, modulation paths or buffers must work before loss/order
contrasts; real nonzero observed loop/freeze/tail before clear/disable. Flags,
preset fields, route names and generation completion alone are insufficient.
Explicit case contexts replace incompatible shared defaults (Quantizer MIDI Off,
Internal pitch, automatic Repeat Off, Mono Gate, latch/release exclusions). A
control-only gesture needs admitted eligible controls, without a sound/hardware
requirement. Unavailable target features, input or hardware are U, never a pass.

`inputs.json` pins 122 immutable inputs, including every one of the 107 old
packet/history files, all 14 original source identities, review/correction files
and the inspected pure parser. The two current canonical pages matched existing
immutable `spec-r2.md`/`research-r2.md` providers at author freeze. Future checks
use those as-of providers, not evolving canonical hashes. No duplicate archive,
consumer edit, old-checker replay, automatic adapter or new workflow framework
is added. `plan.json` holds the manual judgments/proposals, and the checker tests
semantic guards independently even when plan and audit are jointly mutated.

Run `python3 -B check.py --check` here. Only this new checker and the fully
inspected pinned pure source parser execute. It verifies all source/payload
hashes, both historical owner manifests, all 332 raw spans/local-block identities,
all source/catalog/action pointers, 106 browser IDs including U, exact old records,
nulls, resource filtering and whitespace. Seventeen focused negative fixtures
cover omissions, action-pointer errors, inspection promotion, erased true subsets,
unit/fade/order guesses, weak positive baselines, spectral alias reversal, RNG
or completion promotion. A small inline-key/list/table/cell/image/section parser
fixture also passes. Unsupported arguments refuse before input reads; a postseal
watch checks every pinned input and packet file. No old author/capture/validator
or original/vendor/native/UI/audio/MIDI/hardware/network/config/install, media
operation, archive extraction or preset decoding occurs.

Preseal checker-only failures were corrected before any seal: literal token
capitalization, a compact-versus-spaced association assertion, requirement-heading
suffix parsing, and an overbroad exact-body test for the existing U summary form.
They did not change owner/source/old records or add an oracle. All mechanical
passes are integrity evidence, not an application compatibility result.

drum-sampler:B001 HTML:840 31.4 Drum Sampler
drum-sampler:B002 HTML:854 Drum Sampler is an instrument designed for playing back one-shot samples in Drum Racks. It offers key sampler features such as start and length controls, an AHD amplitude envelope, and pitch controls. Drum Sampler also includes a filter section, modulation options, and a set of dedicated playback effects for manipulating samples in various ways.
drum-sampler:B003 HTML:854 31.4.1 Sample Controls Section
drum-sampler:B004 HTML:868 In the Sample Controls section, you can modify the sample’s envelope, pitch, and volume, as well as swap out a loaded sample.
drum-sampler:B005 HTML:868 To load a sample into Drum Sampler, double-click a file in the browser or drag and drop it onto the waveform display.
drum-sampler:B006 HTML:868 The Sample Start slider sets the point where sample playback begins, calculated as a percentage of the sample’s length. Hold Shift while dragging the slider to adjust the start point in fine increments. This also causes the display to zoom in on the waveform.
drum-sampler:B007 HTML:868 The Sample Length slider sets the length of the region that is played, calculated as a percentage of the sample’s total length.
drum-sampler:B008 HTML:868 You can use the Sample Gain slider to adjust the volume of the sample, from -70 to 24 dB.
drum-sampler:B009 HTML:868 Adjusting the Sample Start, Sample Length, and Sample Gain controls also updates the waveform in the display.
drum-sampler:B010 HTML:868 You can use the Attack, Hold, and Decay controls to adjust the sample’s envelope.
drum-sampler:B011 HTML:868 Attack sets the time needed to travel from the envelope’s initial level to its peak level.
drum-sampler:B012 HTML:868 Hold sets the time the envelope’s amplitude level remains at the peak level after reaching the attack time in Trigger mode. You can set the Hold time to inf (i.e., infinite) to play the sample for its entire length. Note that this parameter is disabled when the device’s Envelope Mode is set to Gate.
drum-sampler:B013 HTML:868 Decay sets the time needed to travel from the peak level back to zero after the Hold time is reached in Trigger mode, or once the note is released in Gate mode.
drum-sampler:B014 HTML:868 The Transpose slider sets the global transposition amount, from -48 to 48 semitones, while the Detune slider sets the global detune amount, from -50 to 50 cents.
drum-sampler:B015 HTML:868 Drum Sampler offers two envelope modes: Trigger and Gate. In Trigger mode, the sample continues to play for the duration of the set Hold time after a note is released. In Gate mode, the sample fades out according to the set Decay time once a note is released.
drum-sampler:B016 HTML:868 Hovering over the waveform display reveals additional controls for managing the loaded sample.
drum-sampler:B017 HTML:882 Use the Swap to Next Similar Sample button to cycle through samples that sound similar to the original file. To go back through the options, click the Swap to Previous Similar Sample button. You can also right-click the display and select Show Similar Files to access a list of similar samples in the browser.
drum-sampler:B018 HTML:882 When cycling through samples, you can return to the initially loaded file by right-clicking the waveform display and selecting Return to Reference. To set the currently loaded file as a new reference for swapping, use the Save as Similarity Reference option.
drum-sampler:B019 HTML:882 The hot-swap button opens the Hot-Swap Browser, where you can replace the loaded sample with a different one. To replace Drum Sampler with another instrument, use the hot-swap button in the device’s title bar.
drum-sampler:B020 HTML:882 31.4.2 Playback Effects Section
drum-sampler:B021 HTML:896 You can apply one of nine playback effects to further sculpt a sample’s sound: Stretch, Loop, Pitch Env, Punch, 8-Bit, FM, Ring Mod, Sub Osc, and Noise.
drum-sampler:B022 HTML:896 Each playback effect has two parameters, which can be adjusted via dedicated knobs or by using the X/Y pad. Drag vertically on the X/Y pad to adjust the first parameter, and drag horizontally to adjust the second.
drum-sampler:B023 HTML:896 Use the Playback Effect On toggle to turn this section on or off. When enabled, you can select an effect from the Playback Effect Type drop-down menu.
drum-sampler:B024 HTML:896 Stretch changes the sample’s length without altering its pitch. This produces granular artifacts, which add lo-fi texture to the sound. The Factor control sets the amount of time-stretching as a multiple of the original playback speed. The Grain Size control sets the size of the grain used to time-stretch the sample in milliseconds.
drum-sampler:B025 HTML:896 Loop repeats a portion of the sample. The Loop Offset control sets the loop start point relative to the sample start. The Loop Length control sets the loop’s duration in milliseconds.
drum-sampler:B026 HTML:896 Pitch Env uses an envelope to modulate the pitch of the sample over time. The Pitch Envelope Amount control sets the amount of pitch modulation applied, from -100 to 100%. Positive values result in a higher pitch, while negative values result in a lower pitch. The Pitch Envelope Decay control sets the time it takes for the pitch to return to the base value as defined by the device’s global pitch controls.
drum-sampler:B027 HTML:896 Punch applies ducking with a fixed attack and an envelope shaped to emphasize the sample’s transient. The Punch Amount control sets the amount of ducking applied. The Punch Release control determines how long it takes for the gain reduction to return to zero after the initial trigger.
drum-sampler:B028 HTML:896 8-Bit applies a combination of filtering, bit reduction, and sample rate reduction to recreate the sound of 8-bit CPU chips. The 8-Bit Sample Rate control sets the sample rate at which the sample is played back. The 8-Bit Decay Time control sets the decay time of the effect’s built-in low-pass filter.
drum-sampler:B029 HTML:896 FM uses a sine wave to modulate the sample’s pitch. The Amount control sets the intensity of the frequency modulation, while the FM Frequency control sets the frequency used to modulate the sample’s pitch.
drum-sampler:B030 HTML:896 Ring Mod applies ring modulation to the sample. The Amount control sets how much modulation is applied. The Ring Mod Frequency control sets the frequency used to modulate the sample’s amplitude. Low values produce a tremolo effect, while high values produce artifacts that are typical of ring modulation.
drum-sampler:B031 HTML:896 Sub Osc layers a sub oscillator with the sample. The Sub Oscillator Amount knob sets the oscillator’s level. The oscillator envelope uses the device’s attack and decay settings. The Sub Oscillator Frequency sets the oscillator’s frequency, from 30 to 120 Hz.
drum-sampler:B032 HTML:896 Noise Osc layers a noise oscillator with the sample. The Noise Amount knob sets the oscillator’s level. The oscillator envelope uses the device’s attack and decay settings. The Noise Color control sets the frequency used to filter the oscillator.
drum-sampler:B033 HTML:896 Note that time-based and frequency-related controls in the Stretch, Loop, FM, Ring Mod, Sub Osc, and Noise Osc effects are influenced by the device’s global pitch controls and the MIDI note played. This ensures that each effect’s pitch follows the pitch of the sample as different notes are played or when the sample is transposed.
drum-sampler:B034 HTML:896 Additionally, the modulation decay of the FM and Ring Mod effects is affected by the global decay time. For example, with short decay times, modulation is applied only to the sample’s transient.
drum-sampler:B035 HTML:896 31.4.3 Filter Section
drum-sampler:B036 HTML:910 Use the Filter On toggle to turn the filter on or off.
drum-sampler:B037 HTML:910 There are four filter types to choose from: a 12 dB low-pass filter, a 24 dB low-pass filter, a 24 dB high-pass filter, and a peak filter.
drum-sampler:B038 HTML:910 The low and high-pass filters include dedicated Resonance and Filter Frequency controls. When the peak filter is selected, you can use the Peak Filter Gain and Filter Frequency controls to boost or cut a specific frequency range.
drum-sampler:B039 HTML:910 31.4.4 Global Section
drum-sampler:B040 HTML:924 In the Global Section, you can adjust the output volume, panning, velocity-to-volume ratio, and modulation parameters.
drum-sampler:B041 HTML:924 The Volume control sets the device’s global output level, from -36 to 36 dB, while the Pan slider adjusts the stereo position.
drum-sampler:B042 HTML:924 The Velocity to Volume slider determines how much the device’s volume is modulated by incoming MIDI note velocity.
drum-sampler:B043 HTML:924 Use the Modulation Source toggle to switch between two modulation sources: Velocity or Slide (MPE). Then select a modulation target from the Modulation Destination drop-down menu.
drum-sampler:B044 HTML:924 The Filter target modulates the filter cutoff frequency.
drum-sampler:B045 HTML:924 You can modulate any of the individual envelope stages with the Attack, Hold, and Decay targets.
drum-sampler:B046 HTML:924 Use FX1 and FX2 to modulate the two parameters of the currently selected playback effect.
drum-sampler:B047 HTML:924 The Modulation Amount slider sets the amount of modulation that is applied to the target.
drum-sampler:B048 HTML:924 31.4.5 Context Menu Options for Drum Sampler
drum-sampler:B049 HTML:924 In addition to the usual device context menu entries, there are also a couple of options unique to Drum Sampler.
drum-sampler:B050 HTML:924 Enable Per-Note Pitch Bend — This option allows Drum Sampler to receive per-note pitch bend messages and is enabled by default.
drum-sampler:B051 HTML:924 Envelope Follows Pitch — This scales the amplitude envelope relative to the sample’s pitch. When enabled, the envelope will always affect the same portion of the sample even when the pitch is transposed.
drum-sampler:B052 HTML:924 Drum Sampler > Simpler — This replaces Drum Sampler with Simpler, retaining the sample’s start and length positions.
drum-sampler:B053 HTML:924 When using Drum Racks, you can select the Save as Default Pad option from a pad’s context menu to use Drum Sampler as the default for new samples.
drum-sampler:B054 HTML:944 This means that each time a sample is added to an empty drum pad, an instance of Drum Sampler is automatically loaded.

# D03: conditional Utility Mute kernel trace

**The non-Legacy setter reaches the same byte tested by the kernel.** A narrowly conditional function-local zero-return result is proposed for independent review. There is no application grade, owner adoption, release change or execution. AS OF AUTHOR FREEZE, independent research review is pending; current disposition belongs in the shared indexes. The author also authored the earlier Utility owner R2 and static preflight, and does not independently approve either here.

Let `P` be the valid object supplied to the named wrappers and `K=P+0x48`. For finite float32 `+1.0`, the named OnMute wrapper writes its saved Boolean at `P+0x161`. When its Legacy byte `P+0x162` is zero, it passes `K` and byte 1 to `0x1047bd760`. That setter stores the byte at `K+0xcf`, exactly `P+0x117`. The kernel reads that same byte; it is **not** the saved flag at `P+0x161`.

If the named CalcMain callback is subsequently invoked with the same valid `P`, no intervening writer changes the byte/pointers, and both input sample pointers remain valid, it calls the kernel on `K`. The pinned first instructions zero D0/D1 and branch on that byte's bit 0 directly to RET. The callback stores S0/S1 at `P+0x40/P+0x44`. This proposes two positive-zero output words for this exact invocation and predicate, not a whole-device or public UI Mute law. Muted callback entry still reads its two input pointers before calling the kernel; mute is no excuse for invalid input memory.

The selector's two gate bytes must both equal 1 and its Legacy byte must be zero for the current route. Its literal callback slot `0x106541200` points to the named CalcMain wrapper. The registration helper first writes the callback into its task slot. If the cached entry already matches, it returns without a further call. A changed-cache path invokes untraced `0x101a41ce8`; post-call state, actual delivery and scheduler timing are not proved. The proposal's stable-selector subtrace explicitly requires valid linked memory, a nonzero existing callback and a matching cached entry. Selection alone is not invocation.

If either gate byte is not 1, the selector instead supplies a null callback and writes zero to both stored output words. That inactive path is separate evidence, not proof of Mute or kernel execution. When Legacy equals 1, OnMute selects another route instead of writing the current kernel byte. Legacy Mute slot `0x1065411b0` literally points to `0x1021653a8`, whose calculation body remains metadata-only. Clearing the modern byte with `+0.0` removes this early-return condition; it does not promise nonzero audio, restored signal, downstream tails, or a particular result through the remaining kernel.

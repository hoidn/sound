delay:B001 HTML:928 29.11 Delay
delay:B002 HTML:942 Delay includes independent delay lines for each stereo channel, along with a band-pass filter and LFO modulation options.
delay:B003 HTML:942 The delay time can be set in tempo-synced beat divisions (Sync) or milliseconds (Time). You can switch between these options using the Delay Time Mode toggles.
delay:B004 HTML:942 When set to Sync, you can use the numbered buttons to set the delay time in sixteenth notes. For example, if 4 is selected, the input signal is delayed by four sixteenth notes, which equals one beat (i.e., a quarter note) of delay. Use the Offset sliders to adjust the timing of the sixteenth notes by fractional amounts. Negative values shorten the timing so that the delay occurs slightly earlier than the sixteenth note division, while positive values extend it so that the delay occurs slightly later. You can use Offset to add subtle swing to the delay.
delay:B005 HTML:942 When set to Time, you can delay the input signal anywhere from 1.00 millisecond up to 5.00 seconds.
delay:B006 HTML:942 Activate the Stereo Link toggle to link the delay settings between the left and right channels. Once linked, any adjustments you make to one channel’s delay time are applied to both channels. Offset can be adjusted for each channel independently, even when Stereo Link is enabled.
delay:B007 HTML:942 The Feedback control defines how much of each channel’s output signal is fed back into its delay line input. The feedback loops are independent for each channel, so the signal for the left channel is not fed back into the right channel and vice versa.
delay:B008 HTML:942 You can activate the Freeze button to endlessly cycle the audio in the device’s buffer at the moment the button is pressed. Any new input is ignored until Freeze is deactivated.
delay:B009 HTML:942 The delay signal is preceded by a band-pass filter which can be switched on or off via the Filter toggle. In the display, you can click and drag along the X-axis to adjust the center frequency of the filter, and click and drag along the Y-axis to set the bandwidth. You can also adjust these settings with the Freq and Width sliders.
delay:B010 HTML:942 The delay time and filter frequency can be modulated by an LFO, which makes it possible to achieve a range of sounds from chorus-like effects to chopped glitches.
delay:B011 HTML:942 By default, the full LFO section is collapsed and only the delay time and filter modulation controls are shown below the band-pass display. You can use the LFO Controls toggle to expand the LFO section and access additional modulation options.
delay:B012 HTML:970 The Delay slider sets the amount of LFO modulation that is applied to the delay time, while the Filter slider sets the modulation amount for the filter frequency.
delay:B013 HTML:970 Use the Rate drop-down menu to choose from the following LFO rate modes: Rate, Time, Synced, Triplet, Dotted, and Sixteenth. The LED next to the LFO Controls toggle flashes in time with the current LFO rate during playback.
delay:B014 HTML:970 Select one of the following LFO waveforms via the Wave drop-down: Sine, Triangle, Ramp Up, Ramp Down, Square, S&H (Sample and Hold), or Wander. You can further shape the selected waveform using the Morph slider.
delay:B015 HTML:970 Adjusting the delay time while Delay is processing audio (such as during playback) can cause abrupt changes in the sound of the delay signal. You can choose between three smoothing modes to determine how Delay deals with transitions in timing:
delay:B016 HTML:970 Repitch produces a pitch variation when the delay time is changed, which is similar to the behavior of old tape delay units. This mode is enabled by default.
delay:B017 HTML:970 Fade creates a crossfade between the old and new delay times. This can sound similar to a granular synthesis effect, especially if the delay time is changed gradually.
delay:B018 HTML:970 Jump immediately switches to the new delay time. This can produce audible clicks if the delay time is changed while the previous delay is still decaying.
delay:B019 HTML:970 The LFO modulation for the delay time and filter can also affect the resulting sound differently depending on the selected smoothing mode. You can try adjusting the modulation in each mode to hear how the sound of the delay changes.
delay:B020 HTML:970 Activate the Ping Pong toggle to make the delay signal move back and forth between the left and right channels.
delay:B021 HTML:970 Use the Dry/Wet control to adjust the balance between the dry and processed signals. When using Delay in a return track, set this control to 100% so that only the processed signal is output through the return track.
delay:B022 HTML:970 29.11.1 Context Menu Options for Delay
delay:B023 HTML:970 Two additional modes are available via Delay’s context menu or the Show Options menu in the device title bar: Hi-Quality and Dry/Wet - Equal-Loudness.
delay:B024 HTML:970 Hi-Quality enables a higher quality interpolation for the delay lines when using the Repitch or Fade smoothing mode. Additionally, analog-modeled tape-style smoothing is applied to changes in delay time with Repitch mode.
delay:B025 HTML:970 Dry/Wet - Equal-Loudness switches between linear and equal-loudness behavior for the output. When enabled, the perceived loudness of the dry and processed signals will stay consistent as you adjust the Dry/Wet control. This means a 50/50 mix will sound equally loud for most signals.
delay:B026 HTML:970 29.11.2 Delay Tips
delay:B027 HTML:970 This section includes tips for creating different effects with Delay.
delay:B028 HTML:970 29.11.2.1 Glitch Effect
delay:B029 HTML:970 Enable Stereo Link and set the delay time to 6 in Sync mode. Set Feedback to 50%. Enable the band-pass filter, set the filter frequency to 2.86 kHz, and adjust the Width slider to 2.50. Select the S&H LFO waveform and set the Rate to 0.93 Hz. Set the Delay slider to 66% and adjust the Filter slider to 19%. Select the Fade smoothing mode and make sure Ping Pong is disabled. Set the Dry/Wet control somewhere between 50% - 80% depending on the desired result.
delay:B030 HTML:970 29.11.2.2 Chorus Effect
delay:B031 HTML:970 Disable Stereo Link, set the left channel’s delay time to 12.0 ms, and adjust the right channel’s delay time to 30.0 ms. Set Feedback to 0.0%. Enable the band-pass filter, set the filter frequency to 2.56 kHz, and adjust the Width slider to 8.50. Select the Triangle LFO waveform and set the Rate to 0.65 Hz. Set the Delay slider to 58% and leave the Filter slider set at 0.0%. Select the Repitch smoothing mode and enable Ping Pong. Set the Dry/Wet control somewhere between 45% - 65% depending on the desired result.

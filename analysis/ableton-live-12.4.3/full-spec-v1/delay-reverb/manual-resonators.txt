resonators:B002 HTML:1530 The Resonators effect consists of five parallel resonators that add a tonal character to the input signal and can be tuned in semitones or scale degrees. The effect can produce results ranging from plucked-string timbres to vocoder-like tones. It also supports tuning systems.
resonators:B003 HTML:1530 The input signal passes through a filter first, and then into the resonators. Four filter types are available: low-pass, band-pass, high-pass, and notch. You can use the Frequency parameter to adjust the selected filter’s frequency.
resonators:B004 HTML:1530 The device provides two different resonation modes. Mode A provides a more realistic sounding resonation, while Mode B offers an effect that is especially interesting when Resonator I’s Note parameter is set to lower pitches.
resonators:B005 HTML:1530 The Decay parameter lets you adjust the amount of time it takes for the resonators to be silent after getting an input signal. The resulting sound will be more sustained and tonal with longer decay times, similar to the behavior of an undamped piano string. As with a real string, the decay time depends on the pitch, so low notes will last longer than higher ones. The Const switch applies a constant decay time regardless of pitch.
resonators:B006 HTML:1530 You can adjust the brightness of the resulting sound using the Color control.
resonators:B007 HTML:1530 The first resonator receives both the left and right input channels, while the second and fourth resonators process the left channel, and the third and fifth process the right channel.
resonators:B008 HTML:1530 The tuning of the resonators depends on whether scale awareness is enabled in the effect or not, or if a tuning system is active. By default, the first resonator defines the root pitch and the other four are tuned relative to this pitch in musical intervals. When scale awareness is enabled, the first resonator is tuned relative to the active clip scale in octave 2 and the remaining resonators are tuned relative to its pitch. When a tuning system is active, the first resonator is tuned to an absolute pitch defined by the tuning, while the remaining resonators are tuned relative to its pitch.
resonators:B009 HTML:1530 The Note parameter sets the root pitch of all the resonators. By default, the pitch is set in semitones ranging from C-1 to C5. When scale awareness is enabled, the pitch is set in scale degrees. When a tuning system is active, the pitch is set in note indices based on the tuning system’s set of pitches. You can make fine adjustments in cents using the Resonator I Fine Tuning parameter.
resonators:B010 HTML:1530 All of the resonators have an On/Off toggle and a Gain control. A resonator that is turned off does not consume CPU resources. Turning off the first resonator does not affect the other ones.
resonators:B011 HTML:1530 Resonators II through V follow the Note parameter defined in Resonator I, but they can each be individually transposed by ±24 semitones or ±21 scale degrees (if the effect is scale aware) using their individual Pitch controls. Additional fine tuning is available through the Resonator II–V Fine Tuning parameters.
resonators:B012 HTML:1530 The device features the following output controls: Width, Gain, and Dry/Wet. The Width parameter only affects the wet signal and blends the output of Resonators II-V into a mono signal at 0.0%. Gain adjusts the level of the resonated signal unless Dry/Wet is set to 0%. Dry/Wet adjusts the balance between the processed and unprocessed signals.

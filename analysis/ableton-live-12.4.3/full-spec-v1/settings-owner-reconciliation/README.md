## Read-only verification

Inspect [check.py](check.py), [plan](plan.json) and local bindings, then run:

```sh
python -B analysis/ableton-live-12.4.3/full-spec-v1/settings-owner-reconciliation/check.py --check
```

The finite checker verifies source/audit pins, exact source phrases/locators,
local owner identities and transcriptions, packet-qualified requirement/action
pointers and quoted text, case-association/legacy field roles, actual null/U
flags, Q031 non-adoption, deterministic ledgers, manifest, README links and
authored whitespace. Five rejection fixtures cover a dropped paragraph, changed
quote, invalid pointer, invented actual grade and cross-packet RC-ID collision.
It compares the entire packet hash set before/after and never writes reports.

[Snapshot tool](snapshot.py) and checker `--create` are initial authoring only;
both refuse after the seal. Only this companion directory was written. No
application, original/helper/module function, candidate, model/media, actual
network/service/account, hardware, install or source recapture occurred. Future
absence/no-effect probes still need independently admitted available features,
owned sources and a genuinely productive positive baseline; this companion
supplies none. Root handles any later owner/shared integration and review.

AUTO-B001 /article/body:HTML1 By default, Ableton Live is set to install updates to your current version of Live automatically. This allows Live's performance to benefit from bug fixes and other improvements.
AUTO-B002 /article/body:HTML1 In some cases, a manual update is needed, including:
AUTO-B003 /article/body:HTML2 Push 3 and Move on WindowsTo install Push 3 and Move drivers, install the current version of Live manually from your Ableton account. If Live 11.3.x or Live 12.1.x is installed via auto-update, the Push 3 and Move drivers may not be installed. In this case, both drivers can be downloaded directly from the Download Archive.
AUTO-B004 /article/body:HTML4 Updating Live 11.0From Live 11.0.12, the update to Live 11.1 or later must be installed manually. For more information, see Updating Live. Automatic updates will resume after updating to Live 11.1 or later.
AUTO-B005 /article/body:HTML6 Updating Live 12.2.7 on WindowsOn Windows computers, the update from Live 12.2.7 to Live 12.3. or later must be installed manually. For more information, see Updating Live. Automatic updates will resume after updating to Live 12.3 or later.
AUTO-B006 /article/body:HTML8 To manage Automatic Updates, open Live's Preferences → Licenses/Maintenance, or Licenses & Updates as of Live 12. Under Maintenance → Get Automatic Updates, the dropdown menu can be set to Always, Ask Me, or Never.
AUTO-B007 /article/body:HTML9 If set to Always, the latest release will be installed when it becomes available.
AUTO-B008 /article/body:HTML10 If set to Ask Me, you will be prompted to update when a new version is released.
AUTO-B009 /article/body:HTML11 If set to Never, updates will not automatically download, and you will not be notified of new releases.
AUTO-B010 /article/body:HTML12 If Automatic Updates are set to Always, or if you agree when prompted via Ask Me, available updates will download when Live is opened and an internet connection is active. After an update is installed, changes will not take effect until the Live application is restarted. The updated version will open the next time Live is launched.
AUTO-B011 /article/body:HTML12 If Automatic Updates are not working as expected, or if you encounter an error message, see Troubleshooting Automatic Updates.
AUTO-B012 /article/body:HTML12 For information on updating Packs, see Managing Packs.
AUTO-B013 /article/body:HTML12 Third-party plug-ins, software, and devices must be updated separately, per the manufacturer's instructions. For more information, see Using VST plug-ins on Windows or Using AU and VST plug-ins on Mac.

UPDATE-B008 /article/body:HTML6 Compatibility after updates
UPDATE-B009 /article/body:HTML6 Live Sets can be opened in the Live version in which they were created/saved, and any later version. However, please note:
UPDATE-B010 /article/body:HTML7 Once Live has been updated, if you open and Save a Set, it can no longer be opened in an earlier version. This includes after updating (either automatically or manually) to a new minor or "point" version. For example, Sets saved in Live 12.2 cannot be opened in 12.1 or earlier.
UPDATE-B011 /article/body:HTML8 After updating, you'l be prompted to save a new version of the Set to preserve compatibility. Learn more about Backward Compatibility.

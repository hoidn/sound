How can I install the latest Live version?

If you have automatic updates selected, Live will update automatically when a new version is released. You can also log in to your Ableton account to download the latest version and install it manually, which may be necessary in some cases. 

How do I uninstall Live?

To remove Ableton Live completely from your computer, follow our recommended uninstallation steps for Windows or Mac.  

Should I uninstall previous versions of Live?

Each version of Live is independently installed. You can therefore uninstall previous versions of Live to save space if you don't use them anymore. On Windows, never save or copy any content into Live's installation folder, to avoid losing these files in case you uninstall or (auto-)update Live.

If I upgrade from Lite/Intro to Standard/Suite, do I need to install again?

Each Live edition uses its own installer package. If you've upgraded from Lite/Intro, you can download the Standard/Suite installer from your Ableton account. Once installed, you can then uninstall Lite/Intro. 

If I use the Free Trial, should I uninstall it after it expires?

We suggest uninstalling the Live Trial after it expires. If you've purchased Live after using the Trial, check out our recommendations for installing Live after using the Trial.  

How can I find and install Live Packs?

You can see Live Packs available to download in your Ableton account, on the Packs page, and in Live's Browser under Packs > Available Packs. Check out our guidelines for installing Packs.  

Do I need to update other software when I update Live?

You may need update other software, such as third-party plug-ins and drivers or your OS, to ensure compatibility with Live's current version. For more information, see our guidelines on Updating Live, Live Minimum System Requirements, and Plug-ins on Mac in Live 11.1 and above.

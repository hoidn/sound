RESET-B003 /article/body:HTML3 Resetting Live clears the following and restores to default:
RESET-B004 /article/body:HTML5 Live's Preferences, including Audio and MIDI settings
RESET-B005 /article/body:HTML6 Template Set
RESET-B006 /article/body:HTML7 Undo History
RESET-B007 /article/body:HTML9 After a reset of Live, you'll need to re-enable your hardware devices and plug-in folders, re-enter custom input/output names, and re-select any custom settings in Live's Preferences.
RESET-B008 /article/body:HTML10 Note: The instructions below specify certain files to move to the Desktop. After moving the files, test to see if resetting Live solves the issue. If the issue is indeed solved, you can then delete the files from your Desktop. If the issue is not solved, you can instead move the files back to their original locations to restore your custom settings.

RESET-B010 /article/body:HTML12 Reset Live 11 and later: macOS
RESET-B011 /article/body:HTML13 First, move the Preferences file.
RESET-B012 /article/body:HTML15 Close Live.
RESET-B013 /article/body:HTML18 In Finder, select the Go Menu, then hold down the Option key on your keyboard.
RESET-B014 /article/body:HTML20 Open the Library folder that appears.
RESET-B015 /article/body:HTML22 Scroll down to open the enclosed folders Preferences > Ableton. This opens the path, usually hidden, Users/[username]/Library/Preferences/Ableton. (More info: how to access hidden folders on Mac.)
RESET-B016 /article/body:HTML24 Open the folder for your current version of Live, for example Live 12.0.20.
RESET-B017 /article/body:HTML26 Drag the file Preferences.cfg to the Desktop.
RESET-B018 /article/body:HTML27 If the folder Undo is present, move this as well.
RESET-B019 /article/body:HTML32 Next, reset Live's Template Set:
RESET-B020 /article/body:HTML34 In Live's Browser, navigate to Library/Templates and find the file called DefaultLiveSet.als.
RESET-B021 /article/body:HTML37 Right-click on the file and choose "Set Default Live Set" from the context menu.
RESET-B022 /article/body:HTML42 After these steps, re-launch Live.

RESET-B028 /article/body:HTML54 Find and open the folder for your current version of Live, for example Live 12.0.20, then open Preferences.

RESET-B032 /article/body:HTML64 In Live's Browser, navigate to Library/Templates and find the file called DefaultLiveSet.als.
RESET-B033 /article/body:HTML67 Right-click on the file and choose "Set Default Live Set" from the context menu.

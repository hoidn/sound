OFFLINE-B001 /article/body:HTML1 For Ableton Live versions 5 and and later,you can follow the steps in this guide to authorize Live offline, in the following cases:
OFFLINE-B002 /article/body:HTML3 You cannot successfully authorize online.
OFFLINE-B003 /article/body:HTML4 Your computer is not connected to the internet.
OFFLINE-B004 /article/body:HTML5 To authorize a legacy Live version 4 - 9.
OFFLINE-B005 /article/body:HTML7 Note: When Live is authorized offline, Packs updates and downloads are disabled in Live's Browser.
OFFLINE-B006 /article/body:HTML8 Authorizing Live offline
OFFLINE-B007 /article/body:HTML9 1. Install Live, following steps 1 and 2 in the guide to Installing Ableton Live.
OFFLINE-B008 /article/body:HTML10 2. Launch Live. In the authorization dialog that appears, choose No Internet on this computer.
OFFLINE-B009 /article/body:HTML11 3. The next window will display your computer's hardware code and further information regarding the offline authorization process:
OFFLINE-B010 /article/body:HTML13 4. Make note of the hardware code. You'll need to enter this number in your Ableton.com account. You can also press Save to export this information as a text file for later reference.
OFFLINE-B011 /article/body:HTML14 5. On an internet-connected computer, log in to your Ableton user account. Note that you don't necessarily need to use a second computer to authorize offline. This can be performed on the same computer, as long as it has an internet connection.
OFFLINE-B012 /article/body:HTML15 6. Once logged in, select your Live license from the list and click offline authorization.
OFFLINE-B013 /article/body:HTML16 If your license contains an upgrade, only the highest version included in your license will be shown in the dropdown menu. Select this even if you wish to authorize a previous version. For example, if your license includes both Live 11 and Live 12, the dropdown menu will display Live 12.
OFFLINE-B014 /article/body:HTML18 To see earlier Live versions associated with a license that has been upgraded, choose the relevant license from the dropdown menu and click View serial numbers.
OFFLINE-B015 /article/body:HTML20 Note: If you purchased Live without owning earlier versions of Live and you need to authorize a previous version for compatibility with an older operating system or computer, you can contact Support for options to access previous versions.
OFFLINE-B016 /article/body:HTML21 7. Enter your hardware code from Live and click Download. The Ableton server will generate an authorization (.auz) file for the computer you want to authorize.
OFFLINE-B017 /article/body:HTML23 7a. If using an offline machine, you can save the authorization file to your portable storage device and bring it back to the computer where Live is installed.
OFFLINE-B018 /article/body:HTML24 8. Open Live and double click the .auz file or drag it onto the authorization dialog.

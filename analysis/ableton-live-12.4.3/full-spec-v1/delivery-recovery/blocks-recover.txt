RECOVER-B001 /article/body:HTML1 Live's file recovery process is usually triggered by an undo file in Live's preferences folder. In case the process doesn't happen automatically, or if you clicked "No" on the restore document dialog, the relevant files needed to recover the set are moved into a folder named "Crash" located in Live's preferences folder. Once the files have been renamed and moved out of the folder as explained below, the Set can often be recovered.
RECOVER-B002 /article/body:HTML2 Note: The process of file recovery needs to be accomplished with the same Live version which created the undo file and caused the problem.
RECOVER-B003 /article/body:HTML3 Step 1:
RECOVER-B004 /article/body:HTML4 Make sure Live is not running in the background:
RECOVER-B005 /article/body:HTML6 On macOS, right-click the Live icon in the Dock and choose "Quit".
RECOVER-B006 /article/body:HTML7 On Windows, press Ctrl + Shift + Esc to open the Task Manager, find Live, and click "End Task" if it's still running.
RECOVER-B007 /article/body:HTML9 Locate the following folder and make sure to read our dedicated article on how to access hidden folders:
RECOVER-B008 /article/body:HTML11 WindowsUsers\[Username]\AppData\Roaming\Ableton\Live x.x.x\Preferences\Crash\
RECOVER-B009 /article/body:HTML13 MacUsers/[Username]/Library/Preferences/Ableton/Live x.x.x/Crash/
RECOVER-B010 /article/body:HTML16 Note: Live x.x.x refers to the version number in which the crash occurred, e.g. Live 11.0.5.
RECOVER-B011 /article/body:HTML17 Step 2:
RECOVER-B012 /article/body:HTML18 In the Crash folder, you should find the files and folders that are needed to recover a Set manually:
RECOVER-B013 /article/body:HTML20 BaseFiles
RECOVER-B014 /article/body:HTML21 CrashRecoveryInfo.cfg
RECOVER-B015 /article/body:HTML22 Undo

RECOVER-B017 /article/body:HTML26 Note: In case Live has crashed more than once, you might notice multiple files and folders, each named with the date of a crash. You will only need to use the files and folders corresponding to the crash that you wish to recover.
RECOVER-B018 /article/body:HTML27 Step 3:
RECOVER-B019 /article/body:HTML30 Rename the files by removing the dates from their names:
RECOVER-B020 /article/body:HTML32 Step 4:
RECOVER-B021 /article/body:HTML35 Drag the renamed file and folders into the Parent folder (Preferences -> Ableton -> Live x.x.x.). If a dialog box appears, choose “Replace” for each item.
RECOVER-B022 /article/body:HTML37 Step 5:
RECOVER-B023 /article/body:HTML38 Now start Live. The file recovery process should be triggered again.
RECOVER-B024 /article/body:HTML39 If the file recovery fails, please contact Ableton support and send us Live's latest Crash Report packs. Those packs normally contain the relevant files needed. We will then try to recover the work.

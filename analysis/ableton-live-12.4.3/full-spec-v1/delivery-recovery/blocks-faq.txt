FAQ-B001 /article/body:HTML1 How can I install the latest Live version?
FAQ-B002 /article/body:HTML2 If you have automatic updates selected, Live will update automatically when a new version is released. You can also log in to your Ableton account to download the latest version and install it manually, which may be necessary in some cases.
FAQ-B003 /article/body:HTML3 How do I uninstall Live?
FAQ-B004 /article/body:HTML4 To remove Ableton Live completely from your computer, follow our recommended uninstallation steps for Windows or Mac.
FAQ-B005 /article/body:HTML5 Should I uninstall previous versions of Live?
FAQ-B006 /article/body:HTML6 Each version of Live is independently installed. You can therefore uninstall previous versions of Live to save space if you don't use them anymore. On Windows, never save or copy any content into Live's installation folder, to avoid losing these files in case you uninstall or (auto-)update Live.
FAQ-B007 /article/body:HTML7 If I upgrade from Lite/Intro to Standard/Suite, do I need to install again?
FAQ-B008 /article/body:HTML8 Each Live edition uses its own installer package. If you've upgraded from Lite/Intro, you can download the Standard/Suite installer from your Ableton account. Once installed, you can then uninstall Lite/Intro.
FAQ-B009 /article/body:HTML9 If I use the Free Trial, should I uninstall it after it expires?
FAQ-B010 /article/body:HTML10 We suggest uninstalling the Live Trial after it expires. If you've purchased Live after using the Trial, check out our recommendations for installing Live after using the Trial.
FAQ-B011 /article/body:HTML11 How can I find and install Live Packs?
FAQ-B012 /article/body:HTML12 You can see Live Packs available to download in your Ableton account, on the Packs page, and in Live's Browser under Packs > Available Packs. Check out our guidelines for installing Packs.
FAQ-B013 /article/body:HTML13 Do I need to update other software when I update Live?
FAQ-B014 /article/body:HTML14 You may need update other software, such as third-party plug-ins and drivers or your OS, to ensure compatibility with Live's current version. For more information, see our guidelines on Updating Live, Live Minimum System Requirements, and Plug-ins on Mac in Live 11.1 and above.

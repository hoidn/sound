eq-eight:B02 p # (HTML line 1088) The EQ Eight effect is an equalizer featuring up to eight parametric filters per input channel, useful for changing a sound’s timbre.
eq-eight:B03 p # (HTML line 1088) The input signal can be processed using one of three modes: Stereo, L/R and M/S. Stereo mode uses a single curve to filter both channels of a stereo input equally. L/R mode provides an independently adjustable filter curve for the left and right channels of a stereo input; M/S mode (Mid/Side) provides the same functionality for signals that have been recorded using M/S encoding. In all modes, the frequency spectrum of the output is displayed behind the filter curves when the Analyze switch is on.

eq-eight:B05 p # (HTML line 1088) Each filter has a chooser that allows you to switch between eight responses. From top to bottom in the choosers, these are:
eq-eight:B06 li # (HTML line 1088) 48 or 12 dB/octave Low cut (cuts frequencies below the specified frequency);
eq-eight:B07 li # (HTML line 1088) Low shelf (boosts or cuts frequencies lower than the specified frequency);
eq-eight:B08 li # (HTML line 1088) Peak (boosts or cuts over a range of frequencies);
eq-eight:B09 li # (HTML line 1088) Notch (sharply cuts frequencies within a narrow range);
eq-eight:B10 li # (HTML line 1088) High shelf (boosts or cuts frequencies higher than the specified frequency);
eq-eight:B11 li # (HTML line 1088) 12 or 48 dB/octave High cut (cuts frequencies above the specified frequency).
eq-eight:B12 p # (HTML line 1088) Each filter band can be turned on or off independently with an activator switch below the chooser. Turn off bands that are not in use to save CPU power. To achieve really drastic filtering effects, assign the same parameters to two or more filters.
eq-eight:B13 p # (HTML line 1088) To edit the filter curve, click and drag on the filter dots in the display. Drag-enclose multiple filter dots to adjust them simultaneously, either with the mouse or with your computer keyboard’s arrow keys. Horizontal movement changes the filter frequency, while vertical movement adjusts the filter band’s gain. To adjust the filter Q (also called resonance or bandwidth), hold down the Alt (Win) / Option (Mac) modifier while dragging the mouse. Note that the gain cannot be adjusted for the low cut, notch and high cut filters. In these modes, vertical dragging adjusts the filter Q.

eq-eight:B16 p # (HTML line 1122) With Adaptive Q enabled, the Q amount increases as the amount of boost or cut increases. This results in a more consistent output volume and is based on the behavior of classic analog EQs.
eq-eight:B17 p # (HTML line 1122) To temporarily solo a single filter, enable Audition mode via the headphone icon. In Audition mode, clicking and holding on a filter dot allows you to hear only that filter’s effect on the output.

eq-eight:B20 p # (HTML line 1122) The Scale field will adjust the gain of all filters that support gain (all except low cut, notch and high cut).

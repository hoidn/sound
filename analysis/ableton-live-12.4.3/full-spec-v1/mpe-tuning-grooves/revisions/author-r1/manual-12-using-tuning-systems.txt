0001 15.
0002 Using Tuning Systems
0003 By default Live uses 12TET tuning, this means note pitches are divided equally into twelve parts per octave. However, there are numerous ways that pitches can be distributed across an octave or pseudo-octave (where notes are repeated at a different interval than an octave), and tuning systems can be used to specify these variations.
0004 Live 12 supports
0005 Scala files
0006 , which you can load into a Live Set to use a custom tuning for notes.
0007 The Core Library also comes with a set of tuning systems, which can be found in the Tunings label of the browser. Tuning files from the Core Library use an Ableton-specific extension to the SCL (Scala) file format called
0008 ASCL
0009 .
0010 The Tunings Label in the Browser.
0011 When hovering over or selecting tuning systems in the browser, a short description of the tuning, including the number of notes per octave, is shown in the Info View. This description is also shown when hovering over the name of a
0012 loaded tuning system
0013 .
0014 A Tuning System Description in the Info View.
0015 You can add your own .scl or .ascl files to any folder in Live’s Places so that they show up in the Tunings label of the browser under the User tag.
0016 User-saved Tunings in the Browser.
0017 All of Live’s built-in instruments are supported for use with tuning systems, as well as MPE-enabled plug-ins or external Max for Live instruments, provided that their pitch bend range is set to 48 semitones.
0018 Note that instruments that are not MPE-enabled or use different pitch bend ranges are likely to play out of tune.
0019 15.1
0020 Loading a Tuning System
0021 To load a tuning system into a Set, you can double-click on a tuning file in the browser, or select the file and press
0022 Enter
0023 . These methods will automatically open the Tuning section of the browser, which is hidden by default.
0024 The Tuning section in the Browser.
0025 You can also open the Tuning section using the browser’s view control menu.
0026 The Browser View Control Menu.
0027 External ASCL or SCL files on your computer can be dragged and dropped into the Tuning section as well. As long as the file is loaded in the
0028 Tuning section
0029 , the tuning will be saved with the Live Set.
0030 When a tuning system is added to a Live Set, the notes in the piano roll no longer represent standard MIDI notes, but instead show the corresponding notes of the tuning.
0031 Updated Notes in the MIDI Note Editor.
0032 You can hover over a note in the piano roll to see useful information, such as the note’s pitch and frequency, in the Status Bar. The specified pitch is produced when a note is played in the piano roll or via a keyboard.
0033 Hover Over a Note in the Piano Roll for Pitch Information.
0034 By default, if a tuning system is removed or changed to a different tuning, the position of existing notes in the piano roll is not changed, but the pitches shown in the note ruler are updated to match the new tuning. This means the original notes may not produce the same pitch.
0035 The “Retune Set On Loading Tuning Systems” entry in the Options menu can be enabled so that when a tuning system is loaded or changed, the notes will closely match the pitches of the original notes, ensuring that a melody sounds as close to the original as possible. You will see a dialog appear to confirm this process when loading a tuning system.
0036 Existing MIDI Clips May Be Modified when Loading a Tuning System.
0037 When automatic note retuning is enabled, removing or switching between tuning systems can cause original notes to be changed or lost. This can happen when two notes which overlap in time and originally had different pitches both get mapped to the same pitch in the new tuning system, as that new pitch is closest to both original pitches. In that case, one of the notes may be deleted or shortened.
0038 Note that the Scale Mode choosers in Clip View and the Control Bar are no longer visible when a tuning system is loaded, and the devices that are
0039 scale aware
0040 have their Use Current Scale toggle disabled.
0041 15.2
0042 The Tuning Section
0043 Various pitch settings for a tuning system are accessible via the Tuning section.
0044 The Tuning Section Expanded.
0045 You can toggle the triangle next to the name of the tuning file to expand the section and access additional settings for the lowest and highest notes for the reference pitch.
0046 Tuning
0047 displays the name of the tuning system.
0048 Octave
0049 sets the octave of the note used for the reference pitch.
0050 Note
0051 sets the note in the octave used for the reference pitch.
0052 Ref. Pitch/Freq
0053 sets the frequency of the reference pitch. The pitch of all notes in the Set can be raised or lowered by changing the frequency.
0054 Lowest Note
0055 sets what the lowest note plays by assigning it to an octave and pitch class. Changing the lowest note also affects the highest note, preserving the number of notes in between.
0056 Highest Note
0057 sets what the highest note plays; changing the highest note will also update the lowest note.
0058 Note that the reference pitch is only audibly affected by the Ref. Pitch/Freq value. Changing the Octave or Note values will update the frequency displayed in the Ref. Pitch/Freq slider to match the newly specified notes, however, no audible change is produced until the reference pitch frequency value itself is adjusted. This is to prevent any sudden pitch changes when setting the Octave or Note values.
0059 The floppy disk button to the right of the reference pitch frequency can be used to save the currently loaded tuning as an .ascl file to the Tunings label in the browser.
0060 Pressing the arrow button next to the Save Tuning System button opens a link to
0061 Ableton’s Tuning website
0062 that contains more information about the loaded tuning system, as well as an interactive editor for trying out variations of the associated pitches. You can also export any custom tuning systems you create there. Note that not all tuning systems have external webpages, and the arrow button will be greyed out if no relevant link is available.
0063 You can select a file in the Tuning section and press the
0064 Delete
0065 key to remove it and return to 12TET tuning.
0066 15.3
0067 MIDI Track Options for Tuning Systems
0068 You will see a few tuning-specific options appear in the I/O section of MIDI tracks when a tuning system is loaded that let you customize your track and controller setups.
0069 15.3.1
0070 Bypass Tuning
0071 The Bypass Tuning toggle can be used to ignore a tuning system for a specific MIDI track.
0072 The Bypass Tuning Toggle.
0073 When enabled, the MIDI Note Editor will display 12TET tuning notes in the piano roll for any clips in that track.
0074 Note that MIDI tracks containing Drum Racks automatically bypass any loaded tuning file.
0075 15.3.2
0076 MIDI Controller Layouts
0077 As notes in a tuning system can differ from 12TET layouts, the Track Tuning MIDI Controller Layout settings allow you to specify which notes a controller can be mapped to, as well as create a custom layout if needed. This is useful for re-aligning the layout of an external keyboard to match the piano roll, if the layout differs when using certain tunings.
0078 The Track Tuning MIDI Controller Layout Options.
0079 All Keys
0080 maps notes in the tuning system to all keys on the controller.
0081 Black Keys Only
0082 maps notes to the black keys only. This layout is centered around C#3.
0083 White Keys Only
0084 maps notes to the white keys only. This layout is centered around C3.
0085 Closest in Pitch to Keyboard
0086 maps notes to the closest pitch on the keys.
0087 Custom Controller Layout
0088 lets you define a specific layout for the controller.
0089 When Custom Controller Layout is selected in the chooser, you can press the … button to the right to access the Configure MIDI Layout dialog and adjust the layout settings.
0090 The Configure MIDI Layout Dialog.
0091 Custom controller layouts will be saved and recalled with the Live Set.

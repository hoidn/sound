## Preserved premises and finite batch candidates

A1 is retained as an established **static** post-read gate for Live Set loading,
including note/group/ID/list checks; undo-history clears and the accepted possible
inlined-clear residual stay qualified. A2 qualifies **every saved comparison**
and both carrier constructions. A3 is inferred schema-to-parser binding, not a
per-field dynamic trace. Invalid and special sentinels are not regular finite
values; mixed whitespace/plus Int64 spellings stay U despite a local refusal
reading. Negative IDs and malformed required-field omissions remain excluded.

REQ-006 is the binary64 operation sequence, not mathematically exact rounding
near ties. Negative Time/Duration zero becomes positive zero at grid copy-in,
while small negatives can round to−0. Covered OffVelocity/Probability−0 survives
limits and writes−0. Text−0 in deviation, event TimeOffset/Value and curve
controls has **no expectation** even though held event offsets have scalar grid
results. An on-grid identity statement does not override negative-zero behavior.

[candidate-batches.json](candidate-batches.json) gives four finite retained sets:
128 note limit/grid vectors, nine event-offset vectors,22 held-number texts and
two typed−0 parser results. They reference six exact raw command rows; one row
can contain many calls. These161 result rows and raw command rows are neither
required outcomes nor call counts. The eight getter results are auxiliary only.

Each raw locator records arguments by retained-row identity, original call order,
gdb-script hash/presence, patches, timeout and return code. Existing note/grid
calls use owned buffers; event setup includes the recorded no-op allocator
call`0x1002c4280`. Typed parser calls stop at SetValue stubs using recorded gdb
interception; they do not mutate an actual note field. No selected command row
has recorded `--patch` arguments. Future batches must still check the current

setup or interception does not authorize arbitrary original construction or new
tooling. No future execution is selected here.

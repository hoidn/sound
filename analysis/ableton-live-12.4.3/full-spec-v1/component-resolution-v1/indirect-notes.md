# Indirect-site census and one grounded class cohort

This is packet1a inventory, before the T1 integration map. It grades no outcome and establishes no runtime order, thread delivery, signal routing or public behavior. Root owns the common packet freeze/review and atlas integration.

The immutable retained index baseline is **25,071 sites with at least one exported target reference /268,015 unique sites**. The denominator includes244,762 call-kind sites and23,253 computed jumps. Only21,685 sites have a non-null exported function target; some other exported references are intra-function destinations. No duplicate site rows occur. `indirect-baseline.json` retains both metrics, per-kind counts, target-entry availability and four exact source-row examples. Alias-entry availability is not complete-C-body availability or semantic review.

All24 selected complete C projections were read. Apparent extra recovered constructor arguments in some C are not native ABI proof; native X0 setup controls the association here.

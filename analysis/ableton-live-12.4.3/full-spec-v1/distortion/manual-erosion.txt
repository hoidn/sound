erosion:B002 HTML:1144 Erosion adds digital degradation to the input signal by modulating a short delay using a combination of a sine wave and filtered noise. It can produce a range of effects, from noisy artifacts to downsampling-like distortions.
erosion:B003 HTML:1144 The frequency spectrum of the input signal is shown in the display during playback, along with a visual representation of the modulation. The display also functions as an X-Y controller, which you can use to adjust the Freq and Amount controls. Click and drag along the X-axis to change the sine wave frequency and the center frequency of the noise filter. Drag along the Y-axis to control the modulation amount. You can hold Alt (Win) / Option (Mac) to adjust the filter width of the noise modulation on the Y-axis instead. Note that the filter width has no effect when using only sinusoidal modulation.
erosion:B004 HTML:1144 Noise Blend defines how the sinusoidal and noise modulation carriers are combined. At 0%, only a sine wave is used to modulate the input signal, while at 100%, only noise is used. The sine wave and noise icons below the display change in brightness as you adjust the blend to indicate which modulation carrier is most prominent. In the display, the sinusoidal modulation is represented by a solid vertical line, and the noise modulation is represented by horizontal dotted lines.
erosion:B005 HTML:1144 The Filter Width control defines the bandwidth of the noise filter. Lower values result in a narrower frequency range, while higher values expand it across a wider portion of the spectrum. Note that when Noise Blend is set to 0%, the Filter Width control is grayed out, as it has no effect on the sinusoidal modulation.
erosion:B006 HTML:1144 Use the Stereo Width control to morph from a mono (0.0%) to a stereo (100%) modulation source. Higher values add a subtle stereo enhancement to the modulation.
erosion:B007 HTML:1144 Sets created prior to 12.4 that include Erosion will load the previous version of the device, which is now named Erosion Legacy.

BC-B001 #working-with-the-browser HTML280 4. Working with the Browser
BC-B002 #working-with-the-browser HTML280 Live’s browser is the place where you interact with your library of musical assets: the Core Library of sounds included with the program, any additional sounds you’ve installed via Live Packs, presets, samples you’ve saved, built-in and third-party devices, and any folders on your hard drive that contain samples, tracks, etc. Additionally, you can access files from Ableton Cloud and Push in Standalone Mode via the browser’s Places section.
BC-B003 #working-with-the-browser HTML280 The browser contains several sections and controls for searching, filtering, browsing, and previewing content. These include the search bar, sidebar, filters, content pane, and other tools.
BC-B004 #working-with-the-browser HTML302 The browser’s sidebar contains the Collections, Library, and Places sections and their associated labels.
BC-B005 #working-with-the-browser HTML302 The Browse Back and Browse Forward buttons can be used to access the browser’s previous search or navigation states.
BC-B006 #working-with-the-browser HTML302 The search field helps you find browser items and tagged content.
BC-B007 #working-with-the-browser HTML302 The Show/Hide Filter toggle can be used to show or hide the browser’s filters, while the Filter View menu can be used to specify which filter groups are visible in the Filter View, and to toggle the Tag Editor, Quick Tags, and Auto Tags.
BC-B008 #working-with-the-browser HTML302 The Filter View contains a set of filter groups with associated tags which you can use to search for items in your library.
BC-B009 #working-with-the-browser HTML302 The Results bar appears when searching or filtering. It includes the Add Label button which you can use to save the results in a custom label. When filtering, the bar indicates how many filters are currently applied.
BC-B010 #working-with-the-browser HTML302 The content pane displays the items in whatever label is selected in the browser, or the results of searching and filtering.
BC-B011 #working-with-the-browser HTML302 The Preview tab displays a waveform for samples and clips, and plays back the sound when the Preview toggle is activated.
BC-B012 #working-with-the-browser HTML302 You can adjust how the width is split between the left and right panels of the browser by dragging the middle divider line horizontally. You can also expand the overall size of the browser by dragging its right edge to the right or its bottom edge to the bottom of Live’s window. Note that dragging the browser’s bottom edge will automatically close the Info View, as well the Clip View or Device View (whichever happens to be open).
BC-B013 #working-with-the-browser HTML302 It is also possible to set the browser to take up the full height of the application’s window by selecting the Full-Height Browser option from the View menu. When you select this option, the browser expands to the bottom of Live’s window, but the Info View, as well as the Clip View or Device View (whichever is currently active) remain open.
BC-B014 #working-with-the-browser HTML302 Working in the browser involves choosing one of the labels from the Collections, Library or Places sections in the sidebar, and then filtering or selecting the items that appear in the content pane. You can also use the search bar to look for specific items or tags.
BC-B015 #content-pane HTML302 4.1 Content Pane
BC-B016 #content-pane HTML316 The content pane contains a list of items in a given label or the results of a search or filtering. The Name column is always visible, but you can also show additional columns by selecting them from the Content Options menu.
BC-B017 #content-pane HTML330 Once you select additional columns to be displayed, you can manually reorder them by clicking on a column name and dragging it to the desired position.
BC-B018 #content-pane HTML330 You can sort the items in the content pane in ascending or descending order in any column by clicking on the column name. Note that right-clicking on a column name also opens the Content Options menu.
BC-B019 #content-pane HTML330 The Content Options menu also includes the option to show or hide file extensions for the browser items.
BC-B020 #search-bar HTML330 4.2 Search Bar
BC-B021 #search-bar HTML330 To find browser content, type your desired search term(s) into the search bar. The results will include files that match all search terms, as opposed to any. For example, if you search for “electric bass” any items containing both “electric” and “bass” in their filenames will be displayed.
BC-B022 #search-bar HTML330 To search across all Library locations, select the All label or press CtrlF (Win) / CmdF (Mac) to automatically switch to the All label; this shortcut also places a cursor in the search field.
BC-B023 #search-bar HTML344 You can further refine your search by selecting tags from various filter groups to narrow the results. For example, if you want to find string sounds, you can type “strings” into the search field and then click on any tags in the Filters view to display results matching only those tag descriptions.
BC-B024 #search-bar HTML358 It is also possible to search for content via tags by typing # into the search bar followed by the tag name, e.g., #Drums. Auto-complete suggestions for tag names will appear as you start typing after the hashtag.
BC-B025 #search-bar HTML372 You can click the x button in the search bar to clear any search terms. Note that this does not reset the Filters view. You can use the Clear button in the Results bar to remove any selected tags as well as entered search terms.
BC-B026 #search-bar HTML386 For mouse-free searching, we suggest the following sequence of keyboard actions:
BC-B027 #search-bar HTML386 CtrlF (Win) / CmdF (Mac) to place a cursor in the search field and switch browser focus to the All label;
BC-B028 #search-bar HTML386 Type your search terms or tag names;
BC-B029 #search-bar HTML386 Down arrow key to jump to the search results;
BC-B030 #search-bar HTML386 Up and down arrow keys to scroll the search results;
BC-B031 #search-bar HTML386 Esc to clear the search field and show all items in the All label again. Any selected tags will be cleared as well.
BC-B032 #saving-search-results-as-custom-labels HTML386 4.2.1 Saving Search Results as Custom Labels
BC-B033 #saving-search-results-as-custom-labels HTML386 If you like the results of a particular search and want to quickly access them again in the future, you can create a custom user label containing those search results by clicking the Add Label button to the right of the Clear button.
BC-B034 #saving-search-results-as-custom-labels HTML400 Once saved, you can access the label and its contents like any other label in the Library.
BC-B035 #saving-search-results-as-custom-labels HTML414 You can also use custom labels to store specific items in one place for easy access — similar to using the Collections labels — by tagging content with your own custom tags and then saving the search results into a new label.
BC-B036 #saving-search-results-as-custom-labels HTML414 If you no longer need a custom label you previously added, you can quickly remove it via its right-click context menu.
BC-B037 #saving-search-results-as-custom-labels HTML414 You can use a label’s context menu to rename both factory and custom labels. You can also select a different icon for any label via the context menu, which allows you to further customize your browser.
BC-B038 #browser-history HTML428 4.3 Browser History
BC-B039 #browser-history HTML428 The arrow buttons to the left of the search bar can be used to go forward or backwards in the browser’s history.
BC-B040 #browser-history HTML442 You can also use the following keyboard shortcuts:
BC-B041 #browser-history HTML442 Go forward in the browser’s history: Ctrl] (Win) / Cmd] (Mac)
BC-B042 #browser-history HTML442 Go back in the browser’s history: Ctrl[ (Win) / Cmd[ (Mac)
BC-B043 #browser-history HTML442 The history includes past searches as well as previous navigation states.
BC-B044 #filters-and-tags HTML442 4.4 Filters and Tags
BC-B045 #filters-and-tags HTML442 The browser includes a set of filters which can be used to search specific content using descriptive tags.
BC-B046 #filters-and-tags HTML456 The Filter View section consists of filter groups and their associated tags. You can hide the section by pressing the Show/Hide Filter View toggle, or use the Filter View menu next to the toggle to customize which filter groups are visible.
BC-B047 #filter-groups HTML456 4.4.1 Filter Groups
BC-B048 #filter-groups HTML456 Each filter group contains a set of tags that you can click on to narrow the results that appear in the content pane. To select multiple tags in one group, use the Ctrl (Win) / Cmd (Mac) modifier when clicking on tags.
BC-B049 #filter-groups HTML470 The set of available filter groups is unique to each label, and the state of enabled filters is saved and recalled when moving between Library labels. This means you can customize exactly which groups are shown for every label as needed.
BC-B050 #filter-groups HTML470 To show additional or all filter groups and their tags, use the Filter View menu.
BC-B051 #filter-groups HTML486 You can also right-click on individual filter group names in the Filter View section to hide those groups in a given label. Use the Filter View menu’s Reset Filter Groups to Default option to restore the label to its default set of visible filter groups.
BC-B052 #filter-groups HTML486 The Results bar shows how many filters are applied at any given time. To reset the Filter View and remove any selected tags and search terms, click the Clear button in the Results bar.
BC-B053 #filter-groups HTML486 You can save the filtered results in a custom user label by clicking the Add Label button to the right of the Clear button.
BC-B054 #tags HTML486 4.4.2 Tags
BC-B055 #tags HTML486 Tags are useful for quickly locating or organizing the browser content, especially if you create your own custom tags. Tags can also be a good way to discover content that you are not familiar with yet — simply select one of the tags in the Filter View and browse items associated with the tag.
BC-B056 #tags HTML486 All of Live’s factory content (i.e., content from the Core Library and Live Packs that come with each Live edition) is tagged with a set of descriptive tags. Content from the third-party Packs available in the Ableton webshop is tagged with the tags contained within the “Sounds” filter group.
BC-B057 #tags HTML486 It is not possible to remove the default tags from the factory items; however, you can assign other tags to those items and even add your own custom tags using the Tag Editor.
BC-B058 #tags HTML486 Live periodically runs a sound analysis, and as a part of this process assigns tags to user samples that are up to 60 seconds long. The tag assigned is one that best matches the sound of the sample as per the sound analysis.
BC-B059 #tags HTML486 Auto tags can be toggled using the Enable Auto Tags option in the Filter View menu, and can be removed or changed to user tags in the Tag Editor.
BC-B060 #tags HTML486 Live also assigns tags based on VST3 meta data to VST3 plug-ins in cases where the plug-ins use a VST Sub Category that maps to one of Live’s categories.
BC-B061 #tag-editor HTML486 4.4.3 Tag Editor
BC-B062 #tag-editor HTML486 The Tag Editor allows you to create and assign tags to any items in the browser. You can also create your own tag groups to further organize your tags library.
BC-B063 #tag-editor HTML486 To open the Tag Editor, select the dedicated option from the Filter View menu.
BC-B064 #tag-editor HTML502 Once opened, you will see which tags are currently assigned to the selected browser item from the set of default filter groups.
BC-B065 #tag-editor HTML518 You can fold and unfold the groups by clicking on the arrow next to a group’s name. When a group containing an assigned tag is folded, the arrow is indicated with a bolder background.
BC-B066 #tag-editor HTML530 To assign or remove a tag to or from the selected browser item, check or uncheck the box next to the relevant tag. You can apply multiple tags to the same item by checking multiple boxes. To tag several items at once, hold Shift and select multiple files in the browser before applying the desired tags.
BC-B067 #tag-editor HTML530 You can add custom tags to any filter group using the Add Tag… option at the end each group.
BC-B068 #tag-editor HTML540 You can also create your own groups using the Add Group… option at the bottom of the Tag Editor.
BC-B069 #tag-editor HTML550 Once a new filter group is created you can add custom tags for that group. As soon as you assign a tag from the group to a browser item, the group will appear in the Filter View, as well as in the Filter View menu. This is a good way to organize browser items for specific uses, such as tagging all of your field recordings or vocal samples in their own unique groups for easy access later.
BC-B070 #tag-editor HTML550 Instead of adding multiple specialized groups, you can also add subtags to a default or custom tag. Tags that include subtags are called parent tags. You can fold and unfold parent tags by clicking on the arrow next to a parent tag’s name.
BC-B071 #tag-editor HTML550 To add a subtag, right-click on a tag and choose the Add Subtag in… option. The newly added tag will be nested under the parent tag. Note that it is not possible to create subtags for the tags in the Creator filter group.
BC-B072 #tag-editor HTML562 You can rename or delete custom tags and filter groups via their right-click context menus. Note that it is not possible to edit or remove any of the default filter groups or their associated tags.
BC-B073 #tag-editor HTML562 To close the Tag Editor, press the X button in the upper right corner of the editor or select the relevant option from the Filter View menu.
BC-B074 #quick-tags HTML562 4.4.4 Quick Tags
BC-B075 #quick-tags HTML562 You can quickly view the tags assigned to a selected browser item or assign other tags to it using the Quick Tags section.
BC-B076 #quick-tags HTML576 The Quick Tags section shows any tags assigned to the selected item. You can assign additional tags by clicking Add… and then typing the name of a tag. As you start typing, auto-complete suggestions for tags will appear. Once you assign a tag, it will be added to the Quick Tags section in alphabetical order alongside the factory tags.
BC-B077 #quick-tags HTML576 Apart from assigning existing tags, you can also create new tags directly from the Quick Tags section. To do so, click Add… and start typing the name of a new tag. When you see a Create new tag… prompt appear, press Enter to add the tag. You will then be prompted to select a parent tag or tag group for the new tag.
BC-B078 #quick-tags HTML590 You can select an existing parent tag or group or create a new one. When you type a name that is not recognized as an existing tag or group, you will be prompted again and will have the choice between creating a parent tag or tag group.
BC-B079 #quick-tags HTML604 To remove a tag you assigned to an item, use the X next to the tag’s name. Note that it is not possible to remove the default tags assigned to items.
BC-B080 #quick-tags HTML604 You can assign tags to or remove them from multiple items in the same way as when working with a single item. When multiple items are selected, the Quick Tags section shows all of the tags assigned to any of the items in the selection. Any tags that are not shared between all of the items are marked with an asterisk.
BC-B081 #quick-tags HTML616 When you select a tag name in the Quick Tags section, the Status Bar displays the filter group in which the tag is located.
BC-B082 #quick-tags HTML616 The Quick Tags section is visible by default, but you can hide it via the dedicated Open Quick Tags entry in the Filter View menu.
BC-B083 #collections HTML632 4.5 Collections
BC-B084 #collections HTML632 The Collections labels each have their own assignable color, which you can use to group different browser items together (including folders) in one place. These labels enable you to quickly organize and access particular browser items (for example, your favorite or most-used items).
BC-B085 #collections HTML632 You can assign Collections labels via a selected item’s context menu, or by using the number key shortcuts 1 through to 7. Use 0 to reset color assignments.
BC-B086 #collections HTML632 Note that Collections labels can also be assigned to multiple browser items within a selection. Additionally, it is possible to assign a color label to different item types. For example, you can assign the same color label to a drum sound, a MIDI effect, and a plug-in.
BC-B087 #collections HTML632 Clicking on a Collections label in the sidebar shows all items tagged with that color. Folders that appear in the Collections labels can be unfolded to show their contents.
BC-B088 #collections HTML632 In the content pane, square icons indicate the respective color(s) assigned to each item. Note that although multiple colors can be assigned to an item, no more than three of those colors will be shown in the content pane.
BC-B089 #collections HTML646 Each Collection label can be renamed via its context menu, or by pressing CtrlR (Win) / CmdR (Mac).
BC-B090 #collections HTML646 You can choose which labels are visible in the browser by clicking the Edit button, which will appear when hovering the mouse to the right of the Collections header, and checking the Show/Hide Label option next to each label.
BC-B091 #collections HTML668 To exit Edit Mode, click the Done button.
BC-B092 #collections HTML668 Note that when a hidden unassigned color becomes assigned to a browser item, the Collections label for that color will be shown in the sidebar automatically. However, visible color labels are not automatically hidden if all their assignments are removed.

BC-B102 #library HTML668 Max for Live — all of your Max for Live devices and presets, as well as any Racks that are built with those devices.
BC-B103 #library HTML668 Plug-Ins — your third-party VST and/or Audio Units plug-ins.
BC-B104 #library HTML668 Clips — all of your Live Clips.
BC-B105 #library HTML668 Samples — all of your raw audio samples.
BC-B106 #library HTML668 Grooves — all of your grooves.
BC-B107 #library HTML668 Templates — all of your template Live Sets.
BC-B108 #library HTML668 Tunings — all tuning systems in the Core Library and user-saved .ascl or .scl files.
BC-B109 #library HTML668 By default, all of the Library labels are visible in the browser. You can customize which labels are shown by clicking the Edit button that appears when hovering to the right of the Library header and then selecting or deselecting labels.
BC-B110 #library HTML688 When you are finished, click the Done button to exit Edit Mode.

BC-B120 #places HTML688 User Folder — shows specific folders from any of your hard drives that you’ve added to Live’s browser.

BC-B123 #downloading-and-installing-packs-in-the-browser HTML688 The Packs label in the browser shows all Packs that come pre-installed with Live, any Packs that you’ve installed yourself, and available Pack updates and downloads.

BC-B140 #splice HTML824 4.7.3 Splice
BC-B141 #splice HTML824 Splice is a royalty-free sample library that you can explore to discover new sounds, which can help enhance your music production. Live’s integration with Splice makes it possible for you to access the sample library via the Splice label in the browser.
BC-B142 #splice HTML838 When you click on the Splice label, you will see the Home page, which contains the navigation bar, search bar, Search with Sound drop area, and four sample category buttons that you can use to start browsing the Splice library. You can use the arrows in the navigation bar to step backwards and forwards through all the actions you have taken within the Splice label.
BC-B143 #splice HTML838 You will also find the options to log in with or create a free Splice account at the top of the content pane in the label.
BC-B144 #splice HTML838 The Splice label appears in the sidebar by default, but you can also hide it by right-clicking on the label and selecting “Hide from Sidebar”, or by setting the “Show Splice” option in Live’s Library Settings to Off.
BC-B145 #splice HTML854 Note that an active internet connection is required in order to view the content in the Splice label.
BC-B146 #logging-into-splice HTML854 4.7.3.1 Logging Into Splice
BC-B147 #logging-into-splice HTML854 While you can browse and preview samples as soon as you open the label, you will need to log in with your Splice account to add samples to a Set, save samples to your Splice library, or use the Search with Sound functionality. To log in, click Login at the top of the content pane, or, if you do not have a Splice account yet, click on the Try free button instead. Both options will automatically open the default web browser on your OS and redirect you to Splice’s website, where a device confirmation code will be displayed. The same device confirmation code should be simultaneously displayed in the Splice label in Live. Check that the two codes are the same and press Confirm in the web browser.
BC-B148 #logging-into-splice HTML868 Once you confirm the device, a login page will load in your web browser and you will be able to enter your existing Splice account details or sign up for a new account.
BC-B149 #logging-into-splice HTML882 When you are logged in with your Splice account, the Home page for the label looks slightly different: the Library icon in the navigation bar is no longer grayed out and can be used to access your library of Splice sounds, the sample categories buttons are replaced with different browsing buttons and moved to the top of the page, while the Search with Sound drop area is moved to the bottom of the page.
BC-B150 #searching-for-splice-samples HTML896 4.7.3.2 Searching for Splice Samples
BC-B151 #searching-for-splice-samples HTML896 You can search for samples directly using the search bar. Once you select it, popular search categories are displayed, and you can select one of these suggestions or start typing to search by the term of your choosing. Further suggestions are displayed as you start typing.
BC-B152 #searching-for-splice-samples HTML908 Click on one of the suggestions or press Enter to view the results. Then, choose the “Samples” or “Packs” option at the top of the results to view a list of individual samples or sample packs that contain the search term.
BC-B153 #searching-for-splice-samples HTML922 You can further refine the search results using the filters and tags above the results. You can filter by instrument type, music genre, key, tempo, and sample type (one-shot or loop). The tags listed under the filters change depending on the search term and sample category; you can press the three dots button on the right of the list to expand the tag list.
BC-B154 #searching-for-splice-samples HTML922 The results can be sorted by most popular, relevant, or recent samples, or you can randomize the list by selecting the “Random” option from the drop-down menu or pressing the shuffle button.
BC-B155 #searching-for-splice-samples HTML922 Note that if you are using a free Splice account (or are not logged in), the results will be narrowed down to the samples included with that account; this is indicated by the Included filter at the top of the search results and the “included” tag listed with individual samples. Free Splice accounts come with a library of around 2,500 samples.
BC-B156 #searching-for-splice-samples HTML936 Apart from using the search bar, you can also search for samples using the browsing buttons on the Home page. There are three buttons: Instruments, Genres, and Cinematic FX. Each button opens a view of different sample categories, and each category comes with its own subcategories, of which you can select one to narrow down your search. In the Instruments and Cinematic FX, you can also view all the samples in a given category without selecting one of the subcategories.
BC-B157 #searching-for-splice-samples HTML950 You can also use Splice’s Search with Sound feature to find samples that complement your existing clips. To do so, simply drag a clip from your Set onto the Search with Sound area in the Home page, or make a time selection and click inside the Search with Sound area to capture the selection. The audio will be processed and Splice will return a list of 50 compatible samples. The results page also allows you to replay the sound reference, drag another clip or capture a new selection, and delete the current sound reference.
BC-B158 #working-with-splice-samples HTML964 4.7.3.3 Working with Splice Samples
BC-B159 #working-with-splice-samples HTML964 When you enter a search term, select a sample category, or use the Search with Sound feature, a list of corresponding samples is displayed in the content pane.
BC-B160 #working-with-splice-samples HTML964 The search bar is updated to reflect whichever sample category you are viewing, which means that only the samples within the selected category will be searched when you enter a term into the search bar.
BC-B161 #working-with-splice-samples HTML976 Each of the sample entries in the list contains an image of the pack it belongs to (which you can click to view the entire pack), an icon that indicates whether the sample is a one-shot or loop, the sample name, the tags assigned to the sample, and a context menu that allows you to add the sample to Likes or Collections in your library, or view the sample’s pack.
BC-B162 #working-with-splice-samples HTML976 When you hover over a sample, you will see the sample type icon change to the Play button; click the button to preview the sample. Clicking the sample name automatically starts the preview.

BC-B241 #user-folders HTML1178 4.7.8 User Folders
BC-B242 #user-folders HTML1178 Live’s browser allows you to work with your creative tools regardless of where they are installed on your computer.

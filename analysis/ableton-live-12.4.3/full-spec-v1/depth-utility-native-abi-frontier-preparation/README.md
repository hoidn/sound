# Utility native ABI frontier: preparation only

No capture is selected by this package. Root source preflight, independent
readiness review and a separate actual-capture selection must precede use of
the capture flag. The frozen selection.json is unchanged, SHA256
6fb6333c80c3c8091c7f45149244eacfb23d37e4260a7930da5e123533f7a9ac.
Seven fixed physical ARM64 ranges total 996 bytes / 249 rows. They cover only
the reviewed Utility class/base source ambiguities; they are not complete
control flow, native ABI answers or public identities.

Inspect capture-selected-once.py, then run the data-only check:

`python3 -B capture-selected-once.py --check`

It verifies the seven selected metadata/provider pins and tests synthetic range,
row and mapping corruptions. It reads no image/tool file or selected instruction
bytes, starts no child and writes nothing. It imports no older collector. The
older 32-byte collector was inspected only as data; its main was never invoked.

Only after separate selection, the future command is:

`python3 -B capture-selected-once.py --capture-selected-once 6fb6333c80c3c8091c7f45149244eacfb23d37e4260a7930da5e123533f7a9ac`

The script exclusively creates depth-utility-native-abi-frontier-v1; an existing
success/failure tree refuses reuse. It checks the complete preparation inventory,
selected providers, image/tool hashes, pinned header/load commands and unique
TEXT mapping freshly. Image/tool hashes are read once before and once after the
entire batch. Only the seven exact windows are extracted, followed by seven
bounded existing-Rizin arm64 pdj children, requesting bytes/4 rows each. Raw row
bytes must match extracted bytes exactly. No branch, global, callee or slot is
followed; no analysis, emulation, installation or original-code execution occurs.

Each child records argv, PID, UTC, timeout, exit, raw stdout/stderr and cleanup.
Core dumps are disabled in the child; a new process group and completion/failure
SIGKILL clean inherited descendants. Timeout or error retains partial evidence,
stops the batch and never retries. Selected source/preparation providers only
are watched; no predecessor watch universe is replayed. This check does not test
decoder startup or process-group cleanup by running a child.

All six public bridges and 38 application outcomes remain U. No owner, case,
grade or release changes. A successful future static capture would still require
independent source interpretation; byte equality alone answers no public behavior.

chorus-ensemble:B002 HTML:708 Chorus-Ensemble offers a classic two-delay line chorus with an optional third delay line mode. It can produce a wide range of effects, from subtle thickening, through flanging and vibrato, to string ensemble chorus sounds.
chorus-ensemble:B003 HTML:708 The device’s display shows the active delay lines as waveforms which reflect the currently selected effect mode and settings. Click one of the three buttons in the display to set the device to one of the available modes: Chorus, Ensemble, or Vibrato.
chorus-ensemble:B004 HTML:720 Chorus mode creates a thickened sound by adding two time-modulated delayed signals to the input. Use it to achieve a classic chorus sound that adds light motion to your audio signal.
chorus-ensemble:B005 HTML:720 Ensemble mode is inspired by a thick three-delay line chorus pedal used in the ‘70s. It is based on and shares controls with Chorus mode, but creates a richer, smoother, and more intense chorus sound by using three delayed signals with evenly split modulation phase offsets.
chorus-ensemble:B006 HTML:720 Vibrato mode modulates the signal’s pitch to a greater extent than the Chorus and Ensemble modes, without layering it with a delayed signal. This produces a pronounced pitch variation rather than the thickening effect of the other modes. The shape of the modulation waveform can morph seamlessly from a sine to a triangle and can be used to create the classic “police siren” sound.
chorus-ensemble:B007 HTML:720 Each mode includes the option to enable a high-pass filter. When enabled, the filter reduces the modulation effect on signal components below the frequency set by the High-Pass Frequency slider, ranging from 20.0 Hz to 2.00 kHz.
chorus-ensemble:B008 HTML:720 In addition to the high-pass filter, the Chorus and Ensemble modes include the Width parameter, which sets the stereo width of the wet signal. This in turn adjusts the chorus level balance between the mid and side channels. At 0.0% the signal will be mono, at 100% the balance is equal, and at 200% the chorus level is twice as loud in the sides as in the middle. Width is used for maintaining the level of the effect across the stereo field, which can be helpful during mixing.
chorus-ensemble:B009 HTML:720 Chorus mode includes two additional parameters: Delay Time and Tap Count. The Delay Time chooser gives you the option to set a dynamic or fixed delay. When set to Auto, the delay time is scaled per tap and is directly proportional to the amount of modulation applied. When set to a fixed value, the delay time remains constant rather than scaling with the modulation amount. This makes it easier to produce a stable chorus effect without unwanted phasing or pitch modulation, which can be especially useful for bass or guitar sounds. Use the Taps toggles to switch between one- or two-tap delay. The single tap delay can help achieve simpler, broader chorus textures similar to classic hardware pedals.
chorus-ensemble:B010 HTML:720 Vibrato mode comes with Offset and Shape controls. Offset adjusts the amount of phase offset between the waveforms for the left and right channel. At 180°, the channels will be perfectly out of phase. Use Shape to change the shape of the modulation waveform. At 0.0%, the shape is set to a sine wave, while at 100%, the shape is set to a triangle wave.
chorus-ensemble:B011 HTML:720 Chorus-Ensemble includes modulation parameters which allow you to shape the character of the sound.
chorus-ensemble:B012 HTML:732 Rate sets the modulation rate in Hertz, and can be adjusted either with the dial or by dragging up or down in the display. Turn up Rate for a more drastic chorus sound, or keep it low for more gentle phasing.
chorus-ensemble:B013 HTML:732 Amount adjusts the amplitude of the modulation signals that affects delay times. Higher values result in a stronger time deviation from the unmodulated time setting.
chorus-ensemble:B014 HTML:732 Feedback sets the amount of each channel’s output that is fed back to its input. Increasing this sounds more extreme and tends to increase upper harmonic material, and will also create audible delays if playback is stopped. The feedback signal can be inverted using the Feedback Invert toggle, enabling which results in a “hollow” sound when combined with high feedback values. Note that this control is disabled in Vibrato mode.
chorus-ensemble:B015 HTML:732 Chorus-Ensemble’s global parameters give you control over the device’s output level, tonal warmth, and the balance between the processed and dry signals.
chorus-ensemble:B016 HTML:744 Output sets the amount of gain applied to the processed signal.
chorus-ensemble:B017 HTML:744 Warmth adds slight distortion and filtering for a warmer sound. Try turning it up to achieve a more crunchy sound.
chorus-ensemble:B018 HTML:744 Dry/Wet adjusts the balance between the processed and dry signals. Set it to 100% when using Chorus-Ensemble in a return track. Note that this control is disabled in Vibrato mode.
chorus-ensemble:B019 HTML:744 29.8.1 Chorus-Ensemble Tips
chorus-ensemble:B020 HTML:744 Here are some tips for using Chorus-Ensemble: - Use Ensemble mode at a rate between 1 Hz and 1.8 Hz and 100% Amount on dry guitars to create a typical surf-rock sound. - Automate the Feedback Invert toggle at Feedback levels > 90% to create massive bursts of decaying oscillations.

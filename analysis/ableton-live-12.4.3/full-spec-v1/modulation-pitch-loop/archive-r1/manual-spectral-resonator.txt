spectral-resonator:B001 HTML:1932 29.36 Spectral Resonator
spectral-resonator:B002 HTML:1948 Spectral Resonator transforms an audio signal by applying tuned resonances to its spectrum. You can highlight chosen frequencies of the resonating partials and alter their decay, creating either short percussive reverberations or long washed-out tones. Choose which frequencies are affected through an internal resonator or via an external MIDI sidechain. Similar to a vocoder, you can use the MIDI input to place the resonances in key with its surrounding musical elements, playing the effect polyphonically with up to 16 voices. You can shape the signal further with different modulation modes to add movement and depth or create more fragmented, textural results. The effect also supports scale awareness and tuning systems.
spectral-resonator:B003 HTML:1948 29.36.1 Pitch Mode Section
spectral-resonator:B004 HTML:1964 Spectral Resonator offers two modes that determine how the fundamental pitch of the effect’s resonant harmonics is set: Internal or MIDI.
spectral-resonator:B005 HTML:1964 When the Internal mode is enabled, the device is fixed to a single pitch, while in the MIDI mode the resonator is tuned dynamically according to external note input. Additional controls become available when MIDI mode is enabled:
spectral-resonator:B006 HTML:1964 External Source and Tapping Point let you select any MIDI track as the input source and choose whether the signal is taken before or after MIDI effects in the track’s device chain. To use an external MIDI controller, select it in the Input Type chooser on a MIDI track, then select that track in Spectral Resonator’s External Source chooser.
spectral-resonator:B007 HTML:1964 The Mono/Poly toggle switches between single and polyphonic voice modes. When set to Poly, Spectral Resonator can receive polyphonic material such as chords.
spectral-resonator:B008 HTML:1964 The Polyphony slider sets the number of voices the effect uses, from 2 to 16.
spectral-resonator:B009 HTML:1964 The MIDI Gate toggle determines how the resonator is activated. When set to On, the device functions more like an instrument and will only resonate only while MIDI notes are played. When set to Off, the resonator still responds to audio input, even without incoming notes. Note that MIDI Gate is always active in Poly mode.
spectral-resonator:B010 HTML:1964 Glide adjusts the time it takes for pitch to slide between consecutive notes, in milliseconds. Note that the parameter is only active in Mono mode.
spectral-resonator:B011 HTML:1964 PB sets how much MIDI pitch bend messages shift the resonator’s pitch, from 0-24 semitones. Note that Spectral Resonator is also able to receive MPE data.
spectral-resonator:B012 HTML:1964 29.36.2 Frequency Section
spectral-resonator:B013 HTML:1980 When the Internal pitch mode is enabled, Spectral Resonator is tuned to the frequency set by the Freq control. You can adjust the frequency in Hertz or set it to a specific pitch; to toggle between the two options, use the Frequency Control Mode buttons below the Freq control. If the Use Current Scale toggle is on, the device follows the active clip scale instead. The control becomes SD Shift and can be used to transpose the resonator in scale degrees. Note that if scale awareness is enabled but no scale is active, Spectral Resonator follows the chromatic scale.
spectral-resonator:B014 HTML:1980 When the MIDI mode is enabled, Spectral Resonator is tuned to the frequencies of incoming MIDI notes. The MIDI input can be transposed by ±48 semitones using the Transp. control or by ±28 scale degrees when Use Current Scale is on. When the effect is scale aware, Transp. becomes the SD Shift control.
spectral-resonator:B015 HTML:1980 Spectral Resonator works with tuning systems in both modes. When a tuning system is active, the Freq control in Internal mode and Transp. control in MIDI mode use note indices instead of note names and semitones, respectively.
spectral-resonator:B016 HTML:1980 You can use the Stretch slider to adjust the spacing between the resonant harmonics. Values below 0% compress the distance, while values above 0 expand it. At 100%, only odd harmonics are produced, which leads to a square-wave type sound.
spectral-resonator:B017 HTML:1980 The Shift slider transposes the spectrum of the input signal by ±48 semitones. Note that this affects the signal fed into the device and not the resonator’s own spectrum.
spectral-resonator:B018 HTML:1980 The Decay control sets how long the resonances persist. Higher values produce longer, sustained tones.
spectral-resonator:B019 HTML:1980 HF Damp sets the amount of damping applied to high-frequency partials, while LF Damp sets the amount of damping applied to low-frequency partials. In both cases, the affected frequency ranges shift according to the current pitch (when in Internal mode) or the pitch of the incoming MIDI notes (when in MIDI mode).
spectral-resonator:B020 HTML:1980 29.36.3 Modulation Section
spectral-resonator:B021 HTML:1996 You can set the effect to one of four modulation modes using the respective toggles: None, Chorus, Wander, or Granular. These modes determine how each harmonic’s pitch and amplitude are modulated:
spectral-resonator:B022 HTML:1996 None applies no modulation.
spectral-resonator:B023 HTML:1996 Chorus applies triangle wave modulation to each partial. When Mod Rate is set to 0, this mode only modulates the amplitudes of the partials.
spectral-resonator:B024 HTML:1996 Wander uses random sawtooth waveforms as the modulation source for each partial.
spectral-resonator:B025 HTML:1996 Granular modulates the amplitude of all partials randomly, using exponential decay envelopes. Partials are generated at irregular intervals, and the Mod Rate parameter affects their density.
spectral-resonator:B026 HTML:1996 All modulation modes are also affected by the Mod Rate and Pch. Mod controls. Mod Rate sets the modulation rate, while Pch. Mod adjusts the range of pitch modulation in semitones. Although Pch. Mod displays only a positive value, pitch modulation is bipolar in all modes except Granular, where the grain envelopes are only applied in a positive direction.
spectral-resonator:B027 HTML:1996 29.36.4 Spectrogram
spectral-resonator:B028 HTML:2012 Spectral Resonator includes a spectrogram that displays the activity of frequencies in the dry and wet signals over time. Dry signals are shown in yellow and wet signals in blue. You can hide the spectrogram using the toggle in the upper-left corner of the display. The visualization helps identify which regions of the spectrum are being emphasized or modified by the resonator.
spectral-resonator:B029 HTML:2012 Two controls are integrated into the spectrogram display: Harmonics and Quantize. You can use Harmonics to set the number of resonant harmonics used by the device. Higher values create a brighter sound, while lower values produce a darker timbre. Note that when using polyphony, the number of harmonics is evenly distributed between the voices, resulting in fewer harmonics per voice when high voice counts are used. Increasing harmonics also increases CPU usage.
spectral-resonator:B030 HTML:2012 When Quantize is enabled, each harmonic is quantized to the active scale or tuning system. If no scale or tuning system is active, the harmonics are quantized to chromatic pitches instead.
spectral-resonator:B031 HTML:2012 29.36.5 Global Parameters
spectral-resonator:B032 HTML:2028 The Input Send control sets the amount of gain applied to the processed signal. A built-in limiter prevents the signal from clipping. The LED next to Input Send will light up when the limiter is in use.
spectral-resonator:B033 HTML:2028 The Unison parameter sets the number of unison voices, which are detuned copies of the resonator’s partials. Use the Uni. Amt parameter to adjust the amount of detuning between those voices. Increasing the number of voices thickens the sound, while higher detuning values create a wider and more animated character. In the Wander and Granular modulation modes, each voice is modulated independently, creating especially dense and warbly textures.
spectral-resonator:B034 HTML:2028 The Dry/Wet control adjusts the balance between the processed and unprocessed signals, and affects how prominently each signal appears in the spectrogram. Set Dry/Wet to 100% when using Spectral Resonator in a return track.
spectral-resonator:B035 HTML:2028 29.36.6 Spectral Resonator Tips
spectral-resonator:B036 HTML:2028 Here are some ways you can use Spectral Resonator in your projects:
spectral-resonator:B037 HTML:2028 Create tonal drum loops by placing Spectral Resonator on a drum track and using the MIDI sidechain input to drive specific pitches. This can be used to add rhythm to your track, allowing the drum material to align tonally with other elements such as the bassline.
spectral-resonator:B038 HTML:2028 Set up Spectral Resonator to follow melodic pitches by first converting audio to MIDI with Convert Harmony to New MIDI Track or Convert Melody to New MIDI Track, then routing the generated MIDI track into the effect.
spectral-resonator:B039 HTML:2028 Create reverb-like sounds by setting Freq to a low value, increasing Unison and Uni. Amt values, and using the Wander modulation mode in combination with low Mod Rate and Pch. Mod values. Adjust the Decay parameter to control the “reverb” decay.
spectral-resonator:B040 HTML:2028 Use Spectral Resonator like a vocoder by placing the effect on a vocal track and controlling it via MIDI sidechain input.
spectral-resonator:B041 HTML:2028 Layer harmonics by placing two Spectral Resonators in series and sending different MIDI signals to each one to create overlapping resonant structures.

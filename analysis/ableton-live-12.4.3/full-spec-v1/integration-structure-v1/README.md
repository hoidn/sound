## Evidence parts

The document, transport and mix authors retain separate seeds, full selected
source records, frontier reviews and semantic boundary explanations. Canonical
research nominations distinguish names matched from another architecture from
original arm64 evidence. A command-name registration, lexical class label or
identical field layout cannot supply a handler, receiver or delivery edge.

## Shared search and limits

`trace.py` reads the retained call and indirect indexes and the predecessor's
24 conditional class-slot records. It hashes each entire index stream against
its original manifest. Source row locators include the LF in their raw hashes.
The original indexes and reviewed predecessor remain unchanged.

`hubs.json` ranks the top 1,000 destinations by incoming call-index row
occurrences, preferring the analyzer's resolved thunk target where available.
Numeric native addresses break ties; external metadata keys retain their own
domain and are never coerced into native addresses. The graph has 323,567
source/target function keys, including 1,991 external metadata keys; those are
not distinct callable native bodies. Explicit entry/sink seeds are exempt from
pruning. Pruned references remain in the output, with their original records.

Each direction expands at most 80 nodes and accepts at most 200 candidate edges
per level, in deterministic source/target/site/kind order. Depths 1, 2 and 3 are
separate runs; the responsible analyst reviews each frontier before selecting
the next depth. Budget omissions, pruned edges, unknown indirect sites and
unexpanded frontiers remain explicit. They support no absence claim. Function
intersections alone are not semantic component joins.

Known analyzer indirect references remain weaker than receiver/slot/native-PC
proofs. The predecessor's added targets keep their receiver/vptr premises.
Unresolved jumps and calls are retained with their kind; an intra-function jump
destination is not invented as an inter-component call. A forward/backward
search can therefore end at an unknown bridge without declaring it disconnected.

no hub output was written. The first three depth-one attempts then rejected an
obsolete overlay field name, before writing any traversal result. Both consumer
issues are corrected with discriminating selfchecks and retained failure

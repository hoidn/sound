# Electric encoded classic-pointer site association

Root selected one data-only analysis after approving the raw word/header/LC/stream witness. Root is sole independent peer. Inputs are ONLY the approved owned whole load-command table, four entire streams, and six entire 8-byte words. No original image, old native/source bodies, provider, tool binary, process loader or runtime calls are involved. The previous witness remains immutable.

The complete extractor and checker were read before image-free synthetic controls. Code, exact local source authorities, selected input hashes and method policy are frozen in inputs-manifest.json before whole-stream analysis. extract-sites.py --analyze-once writes one result/receipt exclusively; never replay that mode. Its --check and check-sites.py --check read only owned data. Retained tamper controls explicitly chmod ONLY temporary copies writable, so they reproduce after sealing.

Apple XNU loader.h supplies the compressed tuple description, opcode/type/mask constants, weak-stream relationship and lazy-stream context. The local xexec.c supplies classic pointer offset/count/stride transition shapes. Neither existing parser nor any C code is imported, compiled or executed. The local harness is NOT Apple runtime authority: it ignores rebase type/ordinals/flags, skips applying weak binds and lacks safe operand/range handling. This Python analysis adds bounded checks; it makes no statement about a real loader applying any fixup.

Every stream gets its own completeness/failure cursor. ULEB/SLEB are at most ten bytes and range checked as uint64/int64; symbols terminate within the stream. Address/count/stride arithmetic is checked without uint64 wrap. Segment indexes use LC_SEGMENT_64 order; pointer writes fit vmsize and get explicit file-backed/virtual-only/partial classifications. Repeat opcodes retain finite arithmetic runs, not expanded loops. All six intervals are matched analytically against every run, including unaligned partial overlaps, duplicate sites and cross-stream relations. Input loop progress is bounded by stream bytes; matching is bounded by six targets and at most two candidate iterations per run/target.

Only classic POINTER type1 is supported. Bind's initial/default pointer type follows the local decoder model and is marked implicit per run; this is not formal Apple default-state proof. Rebase requires an explicit type. Threaded0xD0, nonpointer types2/3, unknown opcode/flags, reserved immediates, malformed operands, missing state and invalid ranges stop that stream as unknown. Partial valid runs remain evidence, but incomplete decode never proves absence. Ordinary/weak DONE requires all remaining bytes zero. Lazy DONE is a record boundary: each later record must explicitly reestablish segment and symbol. A previous nonzero addend cannot silently carry or reset; a new SLEB must establish it. Encoded special ordinals remain raw immediate metadata; no provider/library resolution is attempted.

The result associates encoded site tuples with the six stored integers. It does not add a slide, apply rebases/binds, write memory, resolve symbols/providers, decode threaded pointers or establish final pointers, callable targets, class/constructor success, ABI or public behavior. Prior conditional A/O/R/C/inner-receiver/current-vptr premises and REQ002/REQ014/calibration/audio/state gaps remain open. There is no new behavioral fixture, grade, required-unit closure or main-Live site credit.

Corpus: the traced engine

This page runs a JavaScript port of Corpus's signal chain as traced from the device's decompiled code: the dry/wet panpot, gain, band filter, two linked resonators (five modal body types and two waveguides), stereo width, LFO and pitch hub. Controls and presets are Live 12.4.3's own. Live's side is traced too: it passes each stored value to the device unchanged, except FilterMidFreq, which it maps from Hz on a log scale. One question is open for the three position controls; those are marked.

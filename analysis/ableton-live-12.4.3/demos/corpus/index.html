Corpus resonator: real controls, stand-in sound

The controls, their ranges and the 26 presets come from files shipped with Live 12.4.3. The sound does not: it is a textbook modal resonator built from Web Audio filters, because Corpus's own processing code has not been traced yet. Each control says which parts are observed and which are stand-in.

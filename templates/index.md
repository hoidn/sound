# Documentation templates

Copy the relevant template into its canonical domain. Replace placeholders,
assign a unique ID, and add a domain index entry. Template examples are not
evidence and must never be marked verified without actual results.

| Template | Destination and use |
| --- | --- |
| [Source](source.md) | Analyst source summary with provenance and scope |
| [Behavioral specification](spec.md) | Analyst draft with observable requirements and acceptance cases |
| [Implementation](implementation.md) | Candidate module design, code map, and test results |
| [Decision](decision.md) | Governance or implementation choice and consequences |
| [Verification](verification.md) | A scoped original-versus-candidate experiment |
| [Handoff manifest](handoff-manifest.md) | Reviewed, versioned implementation package |

Implementers use only implementation/decision formats and approved handoff
content. Source/spec/verification templates describe analyst-side work; their
presence is not permission to read analysis material.
